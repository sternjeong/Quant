## 이 연구가 묻는 것

- 시장 급락은 약 28개뿐이라 '어떤 급락이 길게 끄나'의 관계를 시장 사건만으로는 추정하기 어렵다. 49 산업 각각에서 같은 정의(업종 총수익이 1년 고점보다 15% 아래)로 업종 급락을 모으면 훨씬 많다.

## 검정력과 한계

- **FAIL 은 효과 없음의 증명이 아니다.** 사건 수가 적어 중간 크기 이하의 효과는 원리적으로 못 잡는다.
- 시대 C 사건(2008~2022)은 crash-cycle-model-v1 보고서에서 이미 보았다. 업종 급락은 이 질문에 처음 쓴다.
- 기울기는 업종 사건으로만 배우고 시장 사건은 중심·기준 확률에만 쓴다. p_lb 도 시장 라벨 집합 기준(업종 기준 확률이 아님).
- 분류기 미적합 사건은 두 판정 모두에서 빠진다(n_unfit). 기준선과 같은 값을 0 차이로 넣지 않는다.
- 업종은 시장과 변동성·고유 위험이 다르다.
- 업종 급락은 시장 급락 때 몰려 있다(실질 표본은 사건 수보다 작다).
- 산업 구성이 시대마다 다르다(늦게 생긴 산업은 그때부터 사건을 만든다).

## 읽는 법

- 핀볼 손실: 최종 깊이 분위수 예측 5개(10·25·50·75·90%)가 실제 최종 깊이에서 빗나간 정도의 평균(전고점 대비 소수). 낮을수록 잘 맞힘.
- 브라이어 점수: 1·2·3·5년 안 회복 확률 예측과 실제(0/1)의 제곱 오차 평균(0~1). 낮을수록 잘 맞힘.
- 회복 확률은 언제나 **예측 시점(asof)부터** h 거래일 안. 252거래일 = 1년.
- d = 기준선 점수 − 모델 점수. 양수면 모델이 더 잘 맞혔다. 판정은 '한눈에'의 검정으로만 한다.
- p_lb = 긴 약세장 확률(기울기 = 업종, 기준 확률·중심 = 그날 라벨을 아는 시장 사건). 기울기가 0 이면 p = π 라 XFER = BASE.
- DD0 = 발생일 전고점 대비(소수), SPEED = ln(고점→발생일 거래일), VOLRATIO = 21일/252일 변동성 배수, RUNUP = 직전 2년 로그 상승.
- 숫자는 과거 사건 분포다. 성과를 약속하지 않는다.
