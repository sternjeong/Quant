# 플레이북 위기 칸 고치기 + 타이밍 대 노출 (regime-playbook-v3)

과세 이연 계좌에서 v1 국면 메뉴의 위기 칸만 현금/시장으로 바꾸고, 같은 노출(선택 시대 베타)의 고정 비중과도 비교한다. 규칙·판정은 SPEC.md(결과 전 고정).

**판정:** Q_CRISIS_CASH(위기 → 현금) **FAIL** · Q_CRISIS_MKT(위기 → 시장) **FAIL**

판정 기준(playbook3-judge/v1): B(1967~2007)·C(2008~) 모두 같은 계좌 시장 대비 세후 ≥ +1%p, 최대낙폭 시장보다 5%p 넘게 깊지 않음, B 월 초과 단측 p < 0.025 — 여기에 같은 노출 대조군에도 지지 않으면 TIMING_HELPS, 지면 BETA_ONLY.

B·C 는 v1·v2 에서 이미 두 번 본 자료다 — 통과도 강한 증거가 아니다.

- Q_CRISIS_CASH: 선택 시대 베타 0.84 → 대조군 M 84% + CASH 16%
- Q_CRISIS_MKT: 선택 시대 베타 1.38 → 대조군 M 62% + L2 38%

## 읽는 법

- '대 대조군'이 음수면 국면 교체 없이 같은 평균 노출(시장 + 2배 고정 비중)만으로 같거나 더 벌었다는 뜻이다 — 이득은 타이밍이 아니라 노출의 값.
- 과세 이연 계좌는 한도(연금저축·IRP 합산 연 1,800만 원 납입)가 있고 5.5% 는 연금소득세 근사다.
- 통과도 엔진·계좌 반영이 아니다. 전진 원장 후보이며 반영은 사용자 확인 뒤 별도 작업이다.
