판정 기준: 급락 고도화 7연구의 판정 15개를 한 족으로 보고 본페로니 α = 0.05/15 = 0.003333(한쪽). 미국 사건 시대 A(1927-07~1966)·B(1967~2007)·C(2008-01~2024-09)를 합친 사건 단위 부호 뒤집기 p < α 이고 A·B·C 각각의 평균도 양수여야 통과. 표본 조건 A ≥ 4·B ≥ 5·C ≥ 4·합친 ≥ 15. 2024-10 이후 발생 사건은 보고만. **v1(crash-cycle-model-v1)은 A·B 만 판정하고 C 는 보고만 했다 — 이번에는 검정력 때문에 C 를 판정에 넣었고, C 의 사건들은 이미 v1 보고서에서 본 것이다.**

## 이 연구가 묻는 것

- v1 의 기준선은 과거 급락 사건 28개의 분포다. 이 연구는 사건 대신 **그때까지의 일별 수익 전체**로 배운다: 발생일의 깊이와 그날의 변동성 상태(GARCH)에서 출발해, 과거 일별 수익을 그날 변동성에 맞게 다시 뽑아 이어 붙인 가상 경로 수천 개를 만든다.

## 사전 기대와 실제

- SIM_M1: 기대 — FAIL 가능성이 높다(통과 약 15%). 변동성이 큰 발생일(1987·2020)에는 분포가 넓어지고, 조용히 미끄러지는 약세장(1973·2000·2008 초입)에서는 좁아져 깊은 꼬리를 놓칠 수 있다. / 실제 — FAIL
- SIM_M2: 기대 — 불확실(통과 약 25%). 기준선 KM 은 발생일 깊이를 무시하지만 모의는 깊이·변동성에 따라 회복 확률이 달라진다. 무작위 보행은 급락 뒤 V자 반등(평균 회귀)을 못 담는다. / 실제 — FAIL

## 읽는 법

- 핀볼 손실: 최종 깊이 분위수 예측 5개(10·25·50·75·90%)가 실제 최종 깊이에서 빗나간 정도의 평균(전고점 대비 소수). 낮을수록 잘 맞힘.
- 브라이어 점수: 1·2·3·5년 안 회복 확률 예측과 실제(0/1)의 제곱 오차 평균(0~1). 낮을수록 잘 맞힘.
- 회복 확률은 언제나 **예측 시점(asof)부터** h 거래일 안. 252거래일 = 1년.
- d = 기준선 점수 − 모델 점수. 양수면 모델이 더 잘 맞혔다. 판정은 '한눈에'의 검정으로만 한다.
- 모의 깊이 = 각 경로의 3년(756거래일) 안 회복 전 최저(v1 최종 깊이와 같은 정의), 회복 = 경로가 전고점에 처음 닿은 날.
- 변동성(연율) = √(252 × 일별 분산). '오늘' = GARCH 가 거른 다음 날 분산, '장기' = 그때까지 전체 표본 분산.
- 숫자는 과거 사건 분포다. 성과를 약속하지 않는다.
