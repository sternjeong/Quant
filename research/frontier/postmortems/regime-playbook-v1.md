# 한계 분석 — regime-playbook-v1 (2026-11-22, 사람 작성)

## 1. 무엇을 물었고 무엇이 나왔나
추세×변동성 4국면마다 7메뉴 중 선택 시대(1929~1966) 승자를 든다. **FAIL.** 고른 메뉴: 조용한 강세 → 소형 가치, 불안한 강세·조용한 약세 → 합성 2배, 위기 → 대형 가치.
확인 시대(1967~2007) 세전 +4.1%p(14.91% 대 10.86%), 세후 근사 +0.9%p(문턱 +1%p 미달), MDD −64.3% 대 −49.2%(문턱 5%p 초과). 2008 이후(보고) 세전 +3.8%p, 세후 +1.7%p.

## 2. 한계
- 세금: 41년 162번 교체 → 세전 +4.1%p 중 약 3%p 가 교체 때 실현된 양도세로 사라짐. **가장 큰 누수.**
- 낙폭: 불안한 강세·조용한 약세에 합성 2배를 고른 탓(선택 시대 1930년대에는 −93.3%).
- 자료: 소형 가치(SMALL HiBM)는 초소형주 비중이 커서 실제로 사기 어렵고 비용이 크다. 메뉴 그냥 보유만으로도 확인 시대 SV +18.6%(시장 +10.9%) — 플레이북 이득의 상당 부분이 '소형 가치 프리미엄'일 수 있다.
- 검정력: 국면 표본이 작은 곳(조용한 약세 35달, 2008 이후 0달)은 판별 불가.

## 3. 국소점
- **조용한 강세 → 소형 가치: 두 시대 모두 LOCAL_HOLDS**(월 +1.09% / +0.71%). 2008 이후는 +0.57%/월이지만 유의하지 않음. 실시간 판정 가능.
- 불안한 강세 → 2배: 2008 이후에만 LOCAL_HOLDS(+1.00%/월).
- 위기 → 대형 가치: 선택 시대 +1.76%/월이 확인 시대 +0.09%로 사라짐(과적합 신호).

## 4. 목표(+7%p)와의 관계
사후 천장 세후 +19~24%p → **원리적으로는 가능**. 실시간 국면만 쓴 정직한 플레이북은 세전 +4%p, 세후 +1~2%p. 국면 정보 천장(같은 시대 보고 고름)은 +5.6%p — 국면 승자가 시대마다 바뀌어 잃는 몫이 크다.
