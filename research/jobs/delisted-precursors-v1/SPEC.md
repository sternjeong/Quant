# 상장폐지·급락 종목 위험신호 연구 (delisted-precursors-v1)

## 연구 질문

현재 살아남은 종목만 조사하는 생존편향을 줄이고, 실제 CRSP 상장폐지 수익률이 큰 손실을 보인 미국 보통주에서 사전에 관찰할 수 있던 경고 신호를 측정한다. CRSP permno로 가격과 상장폐지 표를 연결한다. S&P 500 편출을 상장폐지로 취급하지 않는다. 상폐 자료와 급락 사례는 별도 라벨로 보존한다.

## 데이터 계약

전체 계산 입력은 `data/research_inputs/crsp_delisted/` 아래 `daily.csv`와 `delists.csv`다. `daily.csv` 최소 열은 `permno,date,prc,ret,vol,shrout`; `delists.csv` 최소 열은 `permno,date,dlret,dlstcd`다. CRSP 단위와 날짜, 원본 배포 버전을 함께 적은 `README.txt`를 입력 폴더에 둔다. CSV는 WRDS/CRSP 허가 범위에서 VM에 배치하며, 원본 데이터나 행을 결과물·git에 복사하지 않는다. 결과에는 열 이름, 행 수, 기간, 입력 파일 SHA-256만 기록한다. 코드의 `ret`와 `dlret`는 소수 수익률로 해석한다. CRSP가 정의한 `dlret` -55/-66/-88/-99 특수 결측코드는 손실 사건으로 취급하지 않고 별도 계수한다([CRSP 데이터 정의](https://www.crsp.org/crsp_pdf/crsp-us-stock-indexes-databases-data-descriptions-guide-crspaccess/)). 유효한 상폐 행의 마지막 총수익 검산은 `(1+ret)*(1+dlret)-1`로 한다.

입력이 없거나 필수 열이 빠지면 `NOT_EVALUABLE_DATA` 보고서를 만들고 성공 종료한다. 이는 상폐 리스크 판정 완료가 아니라 데이터 미연결 상태다. 무자료를 생존·실패 어느 쪽으로도 간주하지 않는다.

## 사전 고정 라벨·경고 변수

주 분석 상폐 라벨은 기업별 첫 CRSP `dlret ≤ -0.50`인 상폐 이벤트다. 보조 라벨은 `dlret ≤ -0.80`; 이 기준을 바꾸지 않는다. 상폐일에서 126 거래 관측치 앞을 기준일로 정해 미래정보 누출을 피한다. 기준일 이전 252개 관측치로 6·12개월 총수익 모멘텀, 252일 고점 대비 낙폭, 60일 변동성, 가격 절대값, 20일 평균 거래대금(`abs(prc)*vol`)의 직전 60일 대비 변화를 계산한다. 관측치 252개 미만은 해당 신호 평가에서 제외하고 개수를 보고한다.

비교군은 같은 기준일에 상폐되지 않았고 향후 252 거래일 동안 상폐행이 없으며 같은 달력연도·같은 CRSP SIC 2자리 산업에서 선택한다. CRSP 파일에서 `siccd`가 없으면 산업 매칭 결과는 `NOT_EVALUABLE_INDUSTRY_MATCH`로 명시하고 전체 시장 통제군으로만 보조 비교한다. 신호별 사전 고정 경고 기준: 12개월 모멘텀 ≤ -50%, 고점대비 낙폭 ≤ -60%, 60일 변동성 ≥ 80% 연환산, 가격 절대값 ≤ $5, 거래대금 변화 ≤ -70%. 가격 절대값은 CRSP `prc`가 음수로 표시되는 bid/ask 평균 관례 때문에 절대값으로 계산한다.

## 판정

이 연구는 위험 예측 검증이지 매수 추천기가 아니다. 표본 수·커버리지, 사건/대조군별 경고 비율, 경고별 민감도·양성예측도·위험비(기업 단위 군집 부트스트랩 95% 신뢰구간)를 보고한다. 전체 판정은 사전 고정 상폐 사례 100건 이상과 최소 5년 기간을 만족하면 `EVALUABLE_DESCRIPTIVE`; 그렇지 않으면 `NOT_EVALUABLE_SAMPLE`. 하나의 신호를 종목 회피 규칙으로 권고하려면 사건/대조군의 경고 비율 차이가 양수이고 위험비의 95% 구간 하한이 1 초과여야 하지만, 통과해도 `REVIEW_ONLY`이며 별도 시계열 외부 검증 전에는 엔진에 추가하지 않는다. 스모크는 `SMOKE_ONLY`다.

## 실행

코드와 기준은 데이터 결과를 보기 전에 고정했다. VM 연구 실행기가 전체 분석을 수행한다. 대화 세션/Codespace에서는 합성 자료 `--smoke`만 쓴다. CRSP 원자료는 라이선스 데이터이며, 보고서·연구 결과 커밋에는 통계만 들어간다.
