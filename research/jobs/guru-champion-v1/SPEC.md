# guru-champion-v1 — 거장 보유 우선 새틀라이트를 챔피언에 넣으면 세후로 나은가 (사전 등록 2026-10-15)

**이미 본 데이터를 다시 쓰는 연구다.** 2014~2024 가격과 같은 13F 는 guru-mechanism-v1·새틀라이트 R&D 가 이미 썼다.
그래서 PASS 여도 '전진 원장 수준의 발견'일 뿐이다(docs/RESEARCH_JOBS.md 판정 설계 규칙 3). S-SEED-019 는 이미
전진 원장(`core/forward_tournament_v2.py` 의 S1)에 기록되고 있다. 엔진 반영은 사용자 확인 뒤 별도 작업이다.

## 왜
guru-mechanism-v1 은 S-SEED-019(현 규칙 추세 후보 중 거장 보유 종목 우선, sp500_pit 풀)의 효과를 메커니즘 수준에서 지지했다.
그러나 새틀라이트 슬리브만·세전·같은 풀의 현 규칙 대비였다. 챔피언 전체(코어 85% + 새틀라이트 15%)와 SPY 기반 챔피언에서,
한국 세금까지 넣은 원화 계좌로는 잰 적이 없다.

## 새틀라이트 (core.satellite_lab.run_variant 그대로 — 반기 1·7월 첫 거래일, 상위 3 균등)
- S0: S-SEED-000(라이브 현 규칙), champion40 풀
- S0p: S-SEED-000, sp500_pit 풀(풀 대조군)
- S1: S-SEED-019, sp500_pit 풀. 13F 는 리밸런싱 전날까지 공시된 것만(`core.guru_history.view_from_filings`).

## 챔피언 (core/tax_fx.py, 카카오페이증권 기본값, 3,000만 원 판정 / 1억 원 보고)
| id | 구성 | 역할 |
|---|---|---|
| C0 | 코어 85% + S0 15% | 기준(현 챔피언, satellite-value-v1 의 A 와 같은 비중) |
| C1 | 코어 85% + S1 15% | 후보 |
| C1p | 코어 85% + S0p 15% | 풀 대조군(보고) |
| D0 | SPY 85% + S0 15% | 기준 |
| D1 | SPY 85% + S1 15% | 후보 |

C 계열은 satellite-value-v1 과 같은 규약(목표가 바뀌는 날 모든 종목을 목표로). D 계열은 SPY 를 사서 들고, 매년 1월 첫 거래일에만
85/15 로 맞춘다. 7월 교체일 목표는 1월 이후 배당 포함 가격대로 표류한 비중이다(SPY 몫 유지, 새틀라이트 몫을 새 종목에 균등).

## 구간
판정 2014-01-02(첫 13F 반영 리밸런싱) ~ 2024-09-30. 절반 ~2019-05-31 / 2019-06-01~2024-09-30. 2024-10 이후는 보고만.

## 판정 (C1 vs C0, D1 vs D0 각각) — PASS_FORWARD_CANDIDATE 는 모두 만족할 때
- (a) 판정 구간 세후 연수익 차이 > 0
- (b) 두 절반 모두 > 0
- (c) 판정 구간 원화 MDD 가 기준보다 3%p 넘게 나쁘지 않음(후보 MDD − 기준 MDD ≥ −3%p)
- (d) 126거래일 순환 블록 부트스트랩 1,000회(시드 20261018) 90% 구간 하한 > −0.5%p

그 밖은 FAIL(`classify_fail` 로 FAIL_UNDERPOWERED 구분). noop_guard, 유한하지 않은 수치, 첫 리밸런싱 전 13F 없음은 NOT_EVALUABLE.
검정력 `power_report(10.75, 2)`. C1 vs C1p(풀 고정 거장 효과)·C1p vs C0(풀 효과)·D1 vs C0 는 보고만.
