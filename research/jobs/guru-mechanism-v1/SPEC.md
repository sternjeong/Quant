# 거장 보유 우선 메커니즘 시험 (guru-mechanism-v1)

사전 등록 2026-10-10. 판정 규칙 `guru-mechanism/v1`. 결과를 보기 전에 고정했으며 바꾸려면 새 id 로 다시 등록한다.

## 왜

S-SEED-019 "거장 보유 우선 · 시점별 S&P500 풀"은 현 새틀라이트 규칙의 추세 후보 가운데, 추적 거장 7명(버핏·버리·애크먼·우드·드러켄밀러·테퍼·클라만, 13F 공시일 기준) 중 1명 이상이 보유한 종목을 먼저 산다(상위 3, 6개월 보유). sat-judge/v3 에서 지금까지 가장 강한 새틀라이트 신호였다. 앞 구간 무작위 대비 99백분위, 떼어 둔 구간 샤프 1.82(현 규칙 0.73)였다. 하지만 DSR 0.20(누적 시도 27)이고 이웃 파라미터 관문에서 떨어졌다.

떼어 둔 구간(2024-10-09~)은 이미 여러 연구가 봐서 소진되었다. 그래서 이 연구는 효과를 다시 재지 않고 **메커니즘**을 묻는다. 거장의 안목 때문인가, 아니면 버핏의 AAPL 같은 초대형주·품질주 쏠림이 거장 신호로 위장한 것인가?

## 구간과 엔진

- 평가 구간(IS): 거장 13F 공시가 하나라도 알려진 첫 리밸런싱일부터 2024-10-08 까지다. 13F XML 은 2013년 2분기 보고분(2013-08 공시)부터 있어서 실데이터에서는 2014-01 리밸런싱부터다.
- 2024-10-09 이후 값은 보고만 하고 판정에 쓰지 않는다.
- 풀은 `sp500_pit` 이다. 가격·리밸런싱(1·7월 첫 거래일)·비용(편도 8bp)·시뮬레이터는 `core.satellite_lab` 의 것을 그대로 쓴다.
- 거장 데이터는 `core.guru_history` 의 13F 이력이다. 리밸런싱 전날까지 **공시된** 것만 쓴다(`view_from_filings`). VM 디스크에 7명 모두 있으면 그대로 쓰고(네트워크 없음), 없으면 받아 온다.
- 시총은 그 시점 발행주식수 × 종가 근사로, `core.point_in_time_market_cap` 과 같은 식이다. 분할 이력은 종목마다 한 번만 받는다.

## 변형(고정)

| id | 내용 |
|---|---|
| G0 | 현 규칙 S-SEED-000 을 sp500_pit 에서 돌린 것(기준선) |
| G1 | S-SEED-019 재현(`run_variant` 그대로). 등록부 IS 통계(샤프 0.9999 등)와의 차이를 보고하고, 허용 범위는 ±0.05 다 |
| P1 | 시총 위약. 리밸런싱마다 G1 이 우선한 것과 같은 **수**만큼, 추세 후보 중 그 시점 시총 최상위 종목을 우선한다 |
| P2 | 무작위 위약. 같은 수를 추세 후보 중 무작위로 우선하며 1,000회 돌린다(시드 20261010, 뽑기 i 마다 `[시드, i]`) |
| P3 | 거장 한 명씩 빼기(7개) |
| P4 | 버핏만 |
| P5 | G1 에서 AAPL 을 후보에서 제외한 것. 같은 종목을 뺀 G0 와의 비교도 함께 보고한다 |

선정은 'S-SEED-019 점수 = 현 규칙 점수 + 우선 집합이면 +1000' 으로 분해된다. 위약은 우선 집합만 바꾼다. 이 분해가 날짜마다 `run_variant` 의 G1·G0 선정과 같은지 검산한다.

## 판정

활성 샤프는 G0 대비 일별 초과수익의 연율 샤프이고, 평가 구간에서 잰다.

- (a) G1 활성 샤프가 P2 분포의 95백분위 이상이다.
- (b) G1 활성 샤프가 P1 활성 샤프보다 크다.
- (c) P3 7개 가운데 6개 이상에서 활성 샤프가 0보다 크다.

세 기준을 모두 만족하면 **GURU_MECHANISM_SUPPORTED**, 하나만 실패하면 **PARTIAL**(실패 항목을 표기), 그 밖에는 **NOT_SUPPORTED** 다.

다음 경우에는 **NOT_EVALUABLE** 이다.
- G1 이 G0 와 매일 같다(`noop_guard`).
- 분해 검산이 실패한다.
- 평가 구간 추세 후보의 시총 커버리지가 80% 미만이다.

## 함께 보고하는 것

- 검정력: `power_report(평가 연수, 시도 1)` 과 `power_line`. 실패하면 `classify_fail` 결과를 함께 적는다.
- 변형마다 `noop_guard` 결과.
- 우선 집합과 추세 후보 시총 상위 10의 겹침, G1 매수 종목의 시총 상위 10 비율, G1 과 P1 집합의 자카드.
- 거장별 기여: 빼면 줄어드는 활성 샤프, G1 매수 중 그 거장이 보유한 수, 후보 평균 대비 구간 초과수익.
- 떼어 둔 구간의 활성 샤프와 P2 백분위(보고만).

## 결과의 쓰임

판정과 무관하게 S-SEED-019 는 전진 원장(`core/forward_tournament_v2.py`, 다른 작업에서 구현)에 올린다. 엔진 반영은 사용자 확인 뒤 별도 작업으로 한다.

## 한계

- 13F 종목명을 티커로 맞춘 비율이 보유 평가액의 약 72~78% 다. 맞추지 못한 보유는 '보유 안 함'으로 보인다.
- 상장폐지 종목은 가격이 없다(생존편향).
- 시총은 근사값이다.
- 같은 기간을 여러 연구가 봤다.

## 실행

- 체크포인트(`state.json`, 원자적 쓰기)는 G0·G1 선정, 리밸런싱일별 후보·보유 거장, 시총, P2 진행(50회 배치)을 담는다.
- `RESEARCH_JOB_DEADLINE_EPOCH`(90초 여유)나 SIGTERM 을 받으면 저장하고 종료 코드 3 으로 끝낸다.
- `--smoke` 는 합성 가격과 합성 13F 를 쓰고 네트워크를 쓰지 않으며, P2 를 100회만 돈다. 판정은 `SMOKE_ONLY` 로 표기된다.
