라이브 엔진(`core/champion_strategy.py`)에는 검증되지 않은 사이징 옵션이 이미 있다: `inverse_vol`(20일 변동성 역가중, 한 종목 상한 40%)과
라이브 전용 하프 `kelly`(슬리브 전체 익스포저 배율, "검증 안 됨" 표시). 이 둘을 검증한다.

비중은 라이브처럼 소수 4자리 반올림이라 합이 1 과 최대 ±0.0001 다를 수 있다(차이는 현금).

### Z3 Kelly — 시점 기준 재구현

라이브 `compute_satellite_kelly_exposure` 는 '오늘' 기준 최근 5년 가격을 내려받아서 시점 기준으로 부를 수 없다(core 변경 금지).
그래서 같은 상수(`SATELLITE_KELLY_*` 를 core 에서 그대로 읽음)와 같은 core 함수(`donchian_trailing_stop_positions`·`extract_trades`·
`compute_trade_stats`·`kelly_fraction`)로 job 안에 다시 구현했다. 테스트가 같은 입력에서 라이브 함수와 같은 값을 내는지 확인한다.

- 재선정일 d 의 표본: 그 시점 S&P500 편입 종목(코어 16·SPY 제외)을 티커순으로 앞 120 (라이브: 현재 유니버스 순서 앞 120).
- 거래: 각 종목의 [d − 5년, d) 종가로만 돈치안 20일 돌파 + 고점 대비 15% 추적 손절 거래를 만든다. 창 끝에 열린 거래는 마지막 종가로 평가(라이브와 같음).
  가격이 80일 미만이면 그 종목은 건너뜀.
- 거래 수 < 20 이면 f = 1.0(미적용, 라이브와 같음). 아니면 f = min(0.5 × 풀 켈리, 1.0).

## 판정(주: 챔피언 수준)

챔피언 = 라이브 코어 85% + 새틀라이트 15%, `core/tax_fx.py` 세후 원화(카카오 기본, 3,000만 원; 1억 원은 보고만).
판정 구간 2010-01 첫 선정일 ~ 2024-09-30, 절반 경계 2017-05-31. 2024-10 이후는 보고만.

각 Z1~Z3 는 Z0 대비 **모두** 만족하면 `PASS_FORWARD_CANDIDATE`:
1. 판정 구간 세후 연수익 차이 > 0
2. 앞 절반·뒤 절반 모두 > 0
3. 세전 샤프(USD, BIL 초과수익, 8bp 비용) 가 Z0 보다 높음
4. 원화 MDD 가 Z0 보다 2%p 넘게 나빠지지 않음
5. 126일 블록 부트스트랩 1,000회(시드 20261020) 90% 하한 > −0.5%p

아니면 `research_power.classify_fail`(검정력 `power_report(14.7, 3)`). 일별 차이가 사실상 0 이면 `noop_guard` → `NOT_EVALUABLE`.
