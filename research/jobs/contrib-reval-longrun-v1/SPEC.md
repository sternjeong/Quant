# 목돈 + 월 적립 장기 재평가 (contrib-reval-longrun-v1) — 사전 등록 2026-10-17

## 왜

사용자 목표: 처음 목돈 + 매달 적립으로 엔진을 끝없이 굴리고, 장기적으로 **한국 세후** 시장(SPY)을 이긴다.
서로 독립인 10·20년 구간을 여러 번 주는 자료는 1926년부터의 Ken French 일별 자료뿐이다. 그래서 이 작업이 재평가의 주 근거다.
결과를 보기 전에 아래 규칙을 코드(`run.py` 상수)와 이 문서에 고정했다. 바꾸려면 새 id. 엔진은 바꾸지 않는다.

## 전략 (세전 수익은 원래 연구 함수를 그대로 불러 한 번 만든다)

| 이름 | 내용 | 출처 |
|---|---|---|
| MKT | 기준. Mkt-RF + RF 그냥 보유 | FF3 |
| CORE | FF12 상위 4(252행 모멘텀 > 0), 200행 시장 필터 × 0.5 | core-longrun-v1 `lab.target_weights`/`strategy_returns` |
| I2 | FF12 252행 수익 상위 2, 100%, 매달 | mom-volscale-v1 I2/none/none |
| I2VT20 | I2 + 변동성 20% 맞춤 | mom-volscale-v1 I2/VT20/none |
| MB30 / MB50 | 시장 70/50 + I2VT20 30/50, 매년 1월 첫 거래일 재조정 | — |
| BH50 | 시장 50 + BIG HiPRIOR(연 1% 끌림) 50, 1월 재조정 | mom-proxy-v1 `apply_drag` |
| L15F | 시장 85 + 합성 2배 15(완충 필터 ±2%, 꺼지면 RF), 1월 재조정 | lev-base-v1 `buffered_state`/`synthetic_2x_returns` |

판정 시도 수 n_trials = 7.

## 적립 시뮬레이션

`core/rolling_eval.index_sim`, 정책 `underweight_first`, 처음 금액 1, 편도 10bp(첫 매수·적립 매수·혼합 재조정). 단일 소매 전략은
소매 하나를 자산으로, 혼합은 [시장, 소매] 두 자산(1월 첫 거래일 재조정). 기준(MKT)도 같은 날 같은 적립금을 받는다.

| 시나리오 | 월 적립 / 처음 금액 | 세금용 처음 금액 |
|---|---|---|
| A | 0 | 1,000만 원 |
| **B (판정)** | 0.015 (= 1,000만 원에 15만 원) | 1,000만 원 |
| C | 0.05 (= 300만 원에 15만 원) | 300만 원 |

## 세금 (근사 — 판정에 쓴다)

- `rolling_eval.approx_tax_sim` 과 같은 설정: 지수 수준을 가격으로, 1달러 = 1,300원 고정, 공제 250만 원, 22%, 이월결손금 없음, 수수료 10bp,
  배당세·환전비용 없음, 끝에 청산.
- 산업 단위 보유표에 적용한다(소매 하나를 펀드처럼 들면 안쪽 매매의 양도차익이 사라지므로): CORE·I2·I2VT20 은 매달 다시 맞춤,
  MB 는 **매달** 전체를 (1−w)시장 + w×I2VT20 목표로, BH50 은 1월, L15F 는 1월과 필터 전환일에 전체를 맞춘다
  (원래 혼합은 1월에만/다리만 바꾸므로 세금이 조금 더 잡힌다 — 전략에 불리한 쪽).
- 세금 계수 = 보유표의 세금 있음(tax_fx) 청산 후 최종 ÷ 세금 없음(index_sim, 같은 10bp) 최종. **세후 최종 = 세전(소매 수준) 최종 × 계수**,
  세후 IRR = 같은 적립 흐름에 세후 최종을 넣은 XIRR. (속도: 세금 없는 쪽을 tax_fx 대신 index_sim 으로 — 차이 0.2% 이하를 테스트로 확인.)
- 1930년대에 오늘의 명목 250만 원 공제를 쓰는 것은 매우 거칠다.
- **세금 표본(결과 전 결정)**: 세금은 1·4·7·10월에 시작하는 구간(매달 시작의 1/3)만 계산한다. 세전은 매달 시작 전부.
  근거: 스모크 측정상 세금 구간 하나가 0.3~0.7초, 전부 하면 약 4만 번(5~8시간), 1/3 이면 2~3시간.
  판정 통계(세후 승률·중앙값·하위 10%·MDD)는 모두 이 표본 구간에서 낸다(MDD 는 같은 구간의 세전 시간가중 낙폭).

## 구간

- 10·20년, 매달 첫 거래일 시작(1927-07~), 끝 = 시작 + 연수 이하 마지막 거래일.
- **selection**: 끝 ≤ 1966-12-31. **confirmation**: 시작 ≥ 1967-01, 끝 ≤ 2007-12-31. 둘 다 판정.
- **post2008**: 끝 ≥ 2008-01-01(보고만), 그중 2000년 이후 시작은 따로 표. 1967 을 걸치는 구간은 넣지 않는다.

## 판정 (시나리오 B, 근사 세후)

CONTRIB_BEATS_MARKET ⇔ selection·confirmation × 10·20년 **네 칸 모두**에서:
1. 전략 최종 금액 > 시장인 구간 비율 ≥ 0.70
2. IRR 차이 중앙값 ≥ +0.5%p
3. IRR 차이 하위 10% ≥ −1.5%p
4. 시간가중 MDD 중앙값이 시장보다 5%p 넘게 나쁘지 않음

아니면 FAIL, 또는 관측 IR(확인 구간 1967~2007 연속 세전 계좌의 일별 활성 수익 연 IR)이 최소 검출 효과보다 작으면 FAIL_UNDERPOWERED
(`power_report(41, 7)`). 활성 수익이 매일 0 이거나 칸이 비면 NOT_EVALUABLE. 겹치지 않는 구간 수(effective_independent_windows)를 함께 낸다.
A·C 에도 같은 규칙을 적용해 '적립이 결론을 바꿨나' 표로 보고한다(판정 아님).
