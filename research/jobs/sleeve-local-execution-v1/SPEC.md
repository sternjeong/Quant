# 묶음별 독립 매매의 세후 순효과 — sleeve-local-execution-v1

등록일: 2026-10-19. 고정 설계는 `docs/RETURN_UPGRADE_RESEARCH_DESIGN_20261019.md`의 1번과 공통 평가 절을 따른다. 기계 판정은 `research/return_upgrade/runner.py`에 고정한다. 결과 확인 후 기준을 고치려면 새 ID를 사용한다.

주 계좌는 1,000만 원+매달 15만 원, 동일 SPY 적립 대조, 5년 월별 시작 창(2024-09-30까지 종료)이다. 공통 관문은 승리 비율 70%, 세후 IRR 중앙 차이 +1.0%p, 하위 10% -1.5%p, 전체 계좌 MDD·최악 252일 SPY 대비 5%p 이내, 절대 MDD -40% 이내, 편도 비용 추가 25bp에서도 SPY 우위다. 개선형은 설계 문서의 기존 전략 대비 +0.3/+0.5%p 추가 관문도 쓴다. 2024-10 이후는 판정하지 않는다. 모든 판정은 과거 자료의 전진 검토 후보일 뿐이다.

실행기는 `--out`, `--checkpoint`, `--smoke`를 받는다. 중단 시 체크포인트 뒤 코드 3, 완료 시 코드 0이다. 합성 smoke는 수익 판정이 아니다.

revision 2: 선정일과 연초 리셋일이 겹쳐 모든 종목이 매매 허용일 때 적립금을 리밸런싱 전에 별도 매수하지 않는다. 같은 금액을 기존 기준과 동일하게 현금 투입 후 한 번만 맞춘다. 매매가 제한된 선정일에는 적립금의 부족 종목 매수를 별도로 실행한다. 판정 문턱은 그대로다.

입력 적격성 보정(2026-10-20, revision 3):
매수 전 미상장 종목의 가격은 요구하지 않는다. 보유일과 매도일에는 원종가·조정가 모두 유효해야 한다. 기존 신호·기간·비교대상·판정 문턱은 변경하지 않았다.
