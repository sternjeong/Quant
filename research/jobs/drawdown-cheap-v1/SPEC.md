# 낙폭을 싸게 줄이는 방법 v1 (drawdown-cheap-v1) — 사전 등록 2026-10-12, 트랙 B

## 왜

약 30개 사전 등록 연구가 세후 원화로 SPY 그냥 보유(2010~2026 약 15.1%/년, 원화 최대낙폭 −29.7%)를 넘지 못했다.
트랙 B 는 이기려 하지 않고 **'SPY 대비 수익을 가장 적게 내주고 낙폭을 줄이는 방법이 있는가'** 를 묻는다. (수익 우선 트랙 A 는 별도.)
결과를 보기 전에 아래를 고정했고, 바꾸려면 새 id 로 새로 등록한다. 시도 수는 후보 7개(검정력 계산의 n_trials = 7).

## 자료

- Yahoo ETF(`core.market_data`): SPY, BIL, TLT, GLD, ERC 코어 구성 ETF(`champion_strategy.CORE_UNIVERSE`, 현재 16자산), USDKRW(`tax_fx.usdkrw_series`).
  신호는 Close, 수익·배당은 Adj Close(`tax_fx` 규약). 가격은 2005-06 부터 받아 이동평균·변동성·코어 워밍업에 쓴다.
- Ken French `ff3_daily`: 시장 = Mkt-RF + RF, 현금 = RF. core-longrun-v1 과 같은 평일 달력 정리(`to_weekdays`: 토요일 수익은 다음 평일에 복리로 합침).

## 후보 (판정 셀 7개, 모두 SPY 그냥 보유와 비교)

| id | 규칙 |

| B1_100 / B1_200 | 매달 첫 거래일, **전 거래일 종가** > 전 거래일까지의 SMA(100/200) 이면 그달 SPY 100%, 아니면 BIL 100%. 이동평균을 못 구하면 SPY. |
| B2_10 / B2_12 | 매달 첫 거래일, 노출 = min(1, 목표 ÷ 전 거래일까지 63거래일 SPY 일별 수익(Adj Close)의 연율(√252) 표준편차), 나머지 BIL. 목표 10% / 12%. 변동성을 못 구하거나 0 이면 노출 1. 그달 동안 목표 비중은 고정(가격 표류). |
| B3_85 / B3_70 | SPY 85%/70% + ERC 코어 15%/30%. 코어 = `core_lab.build_weights(CoreConfig(cash="bil", weighting="erc"))`(synthesis-rnd-v1/v2 와 같은 라이브 설정 코어). **슬리브 비율은 매년 첫 거래일에만** 목표로 되돌린다. 코어 내부 비중이 바뀌는 날 SPY 목표는 '표류한 현재 비중'(세전 근사 수익으로 추적)으로 두어 SPY 를 사고팔지 않는다. |
| B4 | SPY 80% + TLT 10% + GLD 10%, 매년 첫 거래일 재조정. |

(`tax_fx.simulate` 는 목표 비중이 바뀌는 날에만 매매하므로, 연 재조정일은 행 전체에 1e−7 크기의 흔들림을 번갈아 곱해 '목표 변경일'로 만든다. 비중 오차 1e−7 로 무시 가능.)
체결은 신호 다음날이 아니라 월·연 첫 거래일 종가이고 신호는 전일 종가까지 — `limits-rnd-v1` 등과 같은 규약이다.

## 기간

- **ETF 시대 판정 구간** 2010-01-04 ~ 2024-09-30. 절반: 전반 2010-01-04~2017-05-31, 후반 2017-06-01~2024-09-30(각각 새 계좌로 따로 굴림).
- 보고만(판정 아님): 2008-01-02~2009-12-31 위기(새 계좌), 2024-10 이후, 판정 구간 계좌의 2020·2022 달력 연도 MDD, 1억 원 시작.
- **장기 판정 구간(B1·B2 만)** 1927-07-01 ~ 2007-12-31, 세전, 프렌치 시장을 'SPY' 로. 현금 = RF, 비용 = 시장 비중 변화 × 2 × 편도 10bp(core-longrun-v1 과 같은 단위).
  전환은 전일 종가 신호 → 당일 수익에 반영. B3·B4 의 장기 판정은 `NOT_APPLICABLE`. 2008~ 은 보고만.
- 세금·수수료·환전: `tax_fx.AccountConfig` 기본값(카카오페이 가정: 수수료 0.1%, 환전 스프레드 0.05%, 양도세 22%·공제 250만 원, 배당 원천 15%, 평균법), 시작금 3,000만 원.

## 지표 정의

- 세후 연수익 = (마지막에 전부 팔았을 때 남는 금액 ÷ 시작금)^(1/연수) − 1 (미실현 양도세 차감, 원화). 연수 = (마지막일 − 첫날)/365.25.
- 원화 MDD = `tax_fx` 가 낸 원화 평가액(세금 납부 반영)의 최대낙폭. 세전은 비용·세금 없는 같은 비중의 원화 환산.
- 회전율 = 수수료 ÷ 수수료율로 거꾸로 구한 거래대금의 절반 ÷ 평균 평가액 ÷ 연수(초기 매수·배당 재투자 포함). 매매일수 = 목표 비중이 바뀐 날 수.

## 사전 등록 판정 (후보마다, 모두 만족해야 PASS)

1. (i) ETF 시대 판정 구간 세후 연수익 ≥ SPY − 1.0%p.
2. (ii) 두 절반 각각 세후 연수익 ≥ SPY − 1.5%p.
3. (iii) ETF 시대 판정 구간 원화 MDD 의 크기 ≤ SPY 의 70% (30% 이상 상대 감소).
4. (iv) B1·B2 는 장기 세전 CAGR ≥ 시장 − 1.0%p 그리고 MDD 크기 ≤ 시장의 70%.

판정 값: B1·B2 모두 만족 → `PASS_FORWARD_CANDIDATE`. B3·B4 는 (i)~(iii) 만족 → `PASS_ETF_ONLY`(전진 원장 후보지만 근거가 약함). 아니면 `FAIL`
(`research_power.classify_fail`: 관측 IR(후보−SPY 원화 일별 수익, ETF 시대)이 최소 검출 IR 이상이거나 0 이하면 `FAIL`, 아니면 `FAIL_UNDERPOWERED`).
후보가 SPY 와 매일 같으면(`noop_guard`) `NOT_EVALUABLE`. 비교 기준(`>=`)은 부동소수 오차 1e−12 허용.
PASS 는 **전진 원장에 올릴 후보**까지이며 채택·엔진 반영이 아니다(사용자 확인 뒤 별도 작업).
