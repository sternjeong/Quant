## 사건·층

- 판정: 해외 3지역 사건, 층 **I1**(< 2008)·**I2**(2008 ~ 2024-09), 동시 급락 군집 단위. 2024-10 이후(IX)는 보고만.
- 미국 사건은 판정에 쓰지 않는다(보고만). 공용 정의의 '미국 C 포함' 결정은 이 연구의 판정과 무관하다. 미국 사건의 결과는 crash-cycle-model-v1 보고서에서 이미 보았다.

## 방법

1. 모든 사건 k(미국·해외)의 표본 밖 BASE(D_k = 발생일): F_k = base_m2(m2_pool(us, D_k), 0), Q_k = base_m1(m1_pool(us, D_k), dd0_k) — 미국만 학습(미국 사건이면 v1 기준선과 같다).
2. 대상 사건 i(D = 발생일), 모델 2: h ∈ (252, 504, 756, 1260) 마다 쌍 [(F_k[h], o_k(h))], k ∈ all_recs, t0_k < D, F_k 있음, o_k(h) 를 D 에 알 수 있음:
   rec_date_k ≤ D 이면 o = 1[R_k ≤ h]; 아니고 D 위치 − t0_k ≥ h 이면 o = 0; 그 밖 제외.
   쌍 ≥ 10(RECAL_MIN) 이면 c_h = argmin −Σ[o log σ(ℓ + c) + (1 − o) log(1 − σ(ℓ + c))] + c²/(2·1²), ℓ_k = logit(clip(F_k[h], 0.01, 0.99))
   (1차원 뉴턴, 시작 0, 최대 50회, |Δc| < 1e−12 이면 멈춤); 아니면 c_h = 0.
   RECAL[h] = σ(logit(clip(F_i[h], 0.01, 0.99)) + c_h), 그다음 h 오름차순 누적 최댓값(회복 확률은 h 에 대해 줄지 않음).
3. 모델 1: K1 = {k ∈ all_recs : t0_k < D, Q_k 있음, 깊이 확정이고 end1_date ≤ D}, n = |K1|. n ≥ 10 이면 q 마다 s = [FD_k − Q_k[q]],
   δ_q = n/(n + 10)·wquantile(s, 1, q); 아니면 δ_q = 0. RECAL[q] = Q_i[q] + δ_q, 5개 값을 오름차순 정렬해 q 순서에 다시 배정, 각각 min(값, dd0_i).
4. 쌍 차이 d1_i = 핀볼(BASE) − 핀볼(RECAL)(깊이 확정·둘 다 있음), d2_i = 브라이어(BASE) − 브라이어(RECAL)(자료 안 회복·둘 다 있음).
   군집(모델별 따로, `lab.clusters`) → `judge_intl` → RECAL_M1, RECAL_M2(연구 5 의 3~5단계와 같음).

## 판정

| 키 | 비교 | 점수 | 통과 라벨 |
|---|---|---|---|
| RECAL_M1 | RECAL vs BASE(미국만 학습) | 평균 핀볼 | BEATS_BASELINE |
| RECAL_M2 | RECAL vs BASE(미국만 학습) | 브라이어(1·2·3·5년) | BEATS_BASELINE |

`lab.judge_intl`: 군집 I1 ≥ 3·I2 ≥ 3·합친 ≥ 10, 무효 가드, I1·I2 평균 모두 양수 + 합친 한쪽 부호 뒤집기 p < α = 0.05/15. 그 밖 FAIL(두 평균 양수면 FAIL_UNDERPOWERED),
표본 미달·무효 → NOT_EVALUABLE. 족 15개 공통 α.

## 검정력·사전 기대

연구 5 와 같은 해외 군집 → 예상 n ≈ 13, 필요 효과 0.91 sd. RECAL_M1 통과 약 8%, RECAL_M2 약 12%(문장 전체는 run.py EXPECTED).

## 편향 방지

이 처방은 v1 의 보정 실패(본 것)를 보고 골랐다 → 미국 사건으로 판정하지 않는다. 방향을 정하지 않는 자기 보정이고, 상수(최소 쌍 10, 로짓 사전분포 sd 1,
분위수 보정 사전 10건)는 '사건 10개면 보정 크기의 절반을 믿는다'는 선험 규칙이다.
