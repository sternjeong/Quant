## 사건 정의 (모든 모델 공통)

- 위치 `t` = 평일 달력 행 번호, 1년 = 252행. 시장 총수익 지수 `L = (1 + mkt).cumprod()`(배당 포함 명목).
- 발생일 `t0`: `dd252_t = L_t / max(L_{t−251..t}) − 1` 이 사건 밖에서 −0.15 이하가 된 첫날. 사건 안에서 `dd252 > −0.05` 가 되면 사건 밖(기존 정의 그대로).
- 전고점: `tP = t0 − 251 + argmax(L[t0−251 : t0+1])`(같은 최댓값이면 가장 이른 위치), `P = L[tP]`. 발생일 깊이 `dd0 = L[t0]/P − 1`.
- 병합: 이번 사건의 `tP` 가 직전 부모 사건의 `tP` 와 같으면 별도 사건으로 세지 않고 부모의 재발생일(`retriggers`)로 붙인다. 모든 모델은 부모 사건만 쓴다.
- 회복: `rec = min{s > t0 : L[s] ≥ P}`, 없으면 오른쪽 중도절단. 회복 기간 `R = rec − t0`(거래일).
- 깊이 측정 종료 `end1 = min(rec, t0 + 756)`(회복이 없으면 `t0 + 756`); `end1` 이 자료 끝을 넘으면 깊이 미확정.
  추가 하락 `y = ln(min(L[t0 : end1+1]) / L[t0])`, 최종 깊이 `FD = (1 + dd0)·exp(y) − 1`, 바닥일 = 그 구간 최저 위치(사후, 보고만).
- 시대(t0 날짜): pre < 1927-07-01 ≤ A ≤ 1966-12-31 < B ≤ 2007-12-31 < C. pre 사건은 학습에만 쓴다.
- 미래 정보 규칙: 발생일·P·dd0·특징 = t0 종가까지. 예측은 t0 종가 기준, 투입은 t0+1 종가부터. rec·end1·y·FD·바닥일은 사후이며, 다른 사건 예측의 학습 자료로 쓰려면 그 예측 시점에 이미 확정되어 있어야 한다.

## 특징 (모두 t0 종가까지; 계산 불가면 NaN)

| 코드 | 식 | 근거 | 필요한 이력 |
|---|---|---|---|
| SPEED | `ln(max(t − tP, 1))` | Goldman 유형 분류: 사건형(빠른 충격)은 얕고 짧다 | 없음 |
| RUNUP | `ln(L[tP] / L[tP − 504])` | Greenwood·Shleifer·You(2019) | tP ≥ 504 |
| FINREL | `ln(F[t]/F[tP]) − ln(L[t]/L[tP])`, F = 12 산업 Money 누적 | Muir(2017) | 없음 |
| RATECHG | `rfa(t) − rfa(t − 252)`, `rfa(u) = 252·mean(rf[u−20 : u+1])` | Lunde·Timmermann(2004) | t ≥ 272 |
| FINREL49 (보고) | FINREL 과 같은 식, 49 산업 Banks·Insur·RlEst·Fin 단순 평균 | 견고성 | 없음 |

## 모델 1 — 하락 깊이

- 목표 FD(전고점 대비 소수). 예측 = 분위수 Q = (0.10, 0.25, 0.50, 0.75, 0.90).
- 학습 집합 `T1(i) = {j ≠ i : end1_j ≤ t0_i}`(깊이가 t0_i 종가까지 확정, 같은 날 허용). `|T1| < 6` 이면 예측 없음.
- 기준선 BASE: 가중치 1 로 `ŷ_q = wquantile(y, w, q)`, `FD̂_q = (1 + dd0_i)·exp(ŷ_q) − 1`.
- 특징 모델 KERNEL_F(F 각각 따로): 가우스 커널 가중 — NaN 이 아닌 학습값 m 개로 μ·σ(ddof=0) 표준화, `m < 6` 또는 `σ ≤ 1e−12` 또는 새 값 NaN 이면 기준선과 같은 예측; 대역폭 `h = 1.06·m^(−1/5)`, `w_j = exp(ℓ_j − max ℓ)`, `ℓ_j = −0.5((z_j − z*)/h)²`; NaN 학습점 가중치 = 나머지 평균; `n_eff = (Σw)²/Σw²` 기록. 표준화·대역폭은 예측마다 그 학습 집합으로 다시 계산.
- 가중 분위수: 가중치 0 제외, 정렬, 중간 누적 확률 `c = cumsum(w) − w/2` 사이 선형 보간, 양 끝은 끝값(같은 가중치면 하젠 type 5).
- 점수: 평균 핀볼 손실 `S_i(M) = mean_q (FD_i − FD̂_q)(q − 1[FD_i < FD̂_q])`, 쌍 차이 `d_i = S_i(BASE) − S_i(KERNEL_F)`(양수 = 특징 모델이 더 잘 맞힘).
- 평가 대상: A·B·C 부모 사건 중 깊이 확정이고 `|T1| ≥ 6`. A·B 판정, C 보고만.
- 보고만: 80% 구간 포함률, 시대별 FD 평균·중앙·최소, y 평균·중앙, 바닥까지 거래일 중앙.

## 모델 2 — 전고점 회복 기간

- 목표 R, 예측 = 회복 확률 `F̂(h) = 1 − Ŝ(h)`, h ∈ HZ = (252, 504, 756, 1260).
- 학습 집합 `T2(i) = {j ≠ i : t0_j < t0_i}`; `rec_j ≤ t0_i` 면 (R_j, 1), 아니면 (t0_i − t0_j, 0). `|T2| < 6` 또는 회복 수 < 3 이면 예측 없음.
- 기준선: 카플란-마이어(w = 1). 특징 모델: 같은 커널 가중의 베란 조건부 KM(같은 시각 중도절단은 위험 집합에 남김, 마지막 관측 뒤는 마지막 값 유지).
- 점수: 브라이어 평균 `B_i = mean_h (1[R_i ≤ h] − F̂_i(h))²`. 평가 대상은 자료 안에서 회복한 사건(미회복은 판정에서 빼고 수를 기록). `d_i = B_i(BASE) − B_i(KERNEL_F)`.
- 보고만: 전체 KM(1·2·3·5년 회복 확률, 중앙 회복 기간), 사후 최종 깊이 구간(FD > −0.25, −0.40 < FD ≤ −0.25, FD ≤ −0.40)별 설명용 KM, 보정표.

## 모델 3 — 투입 일정

### 틀 — 왜 막다른 길의 재시도가 아닌가

선언된 막다른 길(crash-rebound-signal-v1 사후 분석): "급락 중 가격·변동성·뉴스 기반 매수 시점 신호, 문턱·기간 격자 확장 금지".
이 모델은 (1) 발생일 이후 어떤 시장 정보도 보지 않는다 — 투입 날짜와 금액은 발생일에 **달력으로 고정**된다. (2) 바닥을 맞히려 하지 않는다 — "최적점"은 사후에만 알 수 있으므로 사후 최적(ORACLE)은 도달 불가능한 상한으로만 보고한다. (3) 메뉴는 결과를 보기 전에 3개로 고정했고 격자를 넓히지 않는다. (4) "수익이 더 높은가"와 "최악의 순간을 얼마나 덜 아프게 하는가(그 대가는 얼마인가)"를 **따로** 판정한다. 가격 조건부 사다리('더 빠지면 산다')와 모델 1 조건부 일정은 신호 기다리기이므로 판정·보고 모두에서 뺐다.
가장 가까운 기존 연구와의 차이: dca-dip-deploy-v1 은 매달 들어오는 적립금을 바닥 신호까지 기다리는 문제였고(신호 기반), 이번은 급락 발생일에 이미 있는 목돈을 미리 정한 달력대로 나누는 문제다(신호 없음).

기준일이 거래일이 아니면 그 뒤 첫 거래일 d. 대응(위에서부터): (1) `t0_j == d` → 발생일, (2) `t0_j < d` 이고 기준일까지 미회복인 부모 사건 중 가장 늦은 것 → "이 정의로는 독립 사건이 아니다 — … 사건 안"(2001-09 는 2000~2003 사건 안임을 이 문구로 적는다), (3) `d < t0_j ≤ d + 252` 인 첫 사건 → 뒤에 발생, (4) 없음 → "−15% 정의로는 사건이 아님"(1년 안 최저 dd252 함께).
표에는 발생일 읽기(그 시점 학습 집합만 — 확장 창 예측과 같은 값)와 실제(FD·바닥일·회복일·R·일정별 D·G), 그리고 "사건 안"·"뒤에 발생"은 기준일 스냅숏(부트스트랩 없음)을 넣는다.

## 검정력·사전 기대

- `research_power.power_report(39.5, 14)` 와 power_line 한 줄(IR 기준은 일별 활성 수익용 근사이고 실제 기준은 사건 단위 표).

  미리 계산한 참고값: n=5 → 2.27sd·최소 p 0.031(통과 불가) / n=10 → 1.10sd / n=16 → 0.78sd / n=20 → 0.67sd. 예상 합친 n: 모델 1·2 약 16, 모델 3 약 22.
  **중간 크기 이하의 효과는 원리적으로 못 잡는다. FAIL 은 '효과 없음'의 증명이 아니다.**
