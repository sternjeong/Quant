# 상폐 포함 개별주 실적 모멘텀 자료 적격성 — earnings-confirm-momentum-v1

등록일: 2026-10-19. 고정 설계는 `docs/RETURN_UPGRADE_RESEARCH_DESIGN_20261019.md`의 5번과 공통 평가 절을 따른다. 기계 판정은 `research/return_upgrade/runner.py`에 고정한다. 결과 확인 후 기준을 고치려면 새 ID를 사용한다.

주 계좌는 1,000만 원+매달 15만 원, 동일 SPY 적립 대조, 5년 월별 시작 창(2024-09-30까지 종료)이다. 공통 관문은 승리 비율 70%, 세후 IRR 중앙 차이 +1.0%p, 하위 10% -1.5%p, 전체 계좌 MDD·최악 252일 SPY 대비 5%p 이내, 절대 MDD -40% 이내, 편도 비용 추가 25bp에서도 SPY 우위다. 개선형은 설계 문서의 기존 전략 대비 +0.3/+0.5%p 추가 관문도 쓴다. 2024-10 이후는 판정하지 않는다. 모든 판정은 과거 자료의 전진 검토 후보일 뿐이다.

이 작업은 현재 **자료 적격성 감사 단계**다. CRSP 일별/구성종목/상장폐지와 접수시각이 있는 분기 EPS가 모두 있어야 한다. 하나라도 부족하거나 시점별 결합 로더가 검증되지 않았다면 `NOT_EVALUABLE_DATA`를 출력하며 수익률을 만들지 않는다. 자료가 준비되면 별도 revision으로 시점별 로더·실제 판정 코드를 구현하고 smoke/전체 관문을 검증한 뒤 VM에서 실행한다.
