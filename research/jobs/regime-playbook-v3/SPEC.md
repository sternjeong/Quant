# regime-playbook-v3 — 위기 칸 고치기 + 국면 교체가 '같은 노출의 고정 비중'보다 나은가 (사전 등록)

등록 2026-11-22. 가설 장부 H-013(parent: regime-playbook-v2). 규칙·판정은 결과를 보기 전에 고정했다. 바꾸려면 새 id.

## 왜

regime-playbook-v2(4/4 FAIL)에서 과세 이연 계좌 변형(P_TAXFREE)은 같은 계좌 시장 대비 세후 **+4.06%p(1967~2007) / +3.78%p(2008~)** 로
수익 조건은 넘었지만 최대낙폭(−64.3% / −61.8%, 시장 −49.2% / −51.1%) 하나로 탈락했다. 한계 분석에서 나온 두 취약점:

1. **낙폭의 원인은 2배가 아니라 '위기 → 대형 가치' 칸**이다. 2배 자리를 시장으로 바꿔도 2008 이후 낙폭이 −61.8% 그대로였다(대형 가치 = 2008 금융주).
   위기 칸은 v1 에서 이미 과적합 신호(선택 시대 월 +1.76% → 확인 시대 +0.09%)를 보였다.
2. **이득이 국면 타이밍인지 그냥 노출(베타)인지** 구분되지 않았다. 2배를 빼면 이득이 사라졌다(B +2.26%p, C −0.39%p).

## 고정한 것

- 국면·메뉴·자료·교체 비용은 v1 그대로(v1 의 run.py 를 불러 쓴다). 계좌는 **과세 이연 계좌만**(v2 에서 일반 계좌는 교체 세금으로 모두 탈락): 교체 때 세금 없음, 끝에 이익의 5.5%.
- 국면별 메뉴: 조용한 강세 → 소형 가치(SV) · 불안한 강세 → 합성 2배(L2) · 조용한 약세 → 합성 2배(L2) · 위기 → **아래 변형마다 다름**.

## 같은 노출의 고정 비중(대조군, 변형마다 따로)

- 변형의 월 수익을 시장 월 초과수익에 회귀한 베타를 **선택 시대(1929~1966)에서만** 추정한다(β_sel).
- 대조군 = 매달 첫날 비중을 되돌리는 시장 (2 − β_sel) + 합성 2배 (β_sel − 1). β_sel 이 1 미만이면 시장 β_sel + 현금 (1 − β_sel), 2 초과면 합성 2배 100%.
- 같은 과세 이연 계좌에서 굴린다(끝에 이익의 5.5%). 되돌림 비용 = 비중 차이 × 0.15%.

## 판정(playbook3-judge/v1, 변형마다)

구간 B = 1967-01-01 ~ 2007-12-31, C = 2008-01-01 ~ 자료 끝. **두 구간 모두 v1·v2 에서 이미 두 번 본 자료다.**

- **TIMING_HELPS**: B·C 모두 (a) 같은 계좌 시장 대비 세후 초과 ≥ +1.0%p, (b) 같은 노출 대조군 대비 세후 초과 ≥ 0, (c) 최대낙폭이 시장보다 5%p 넘게 깊지 않음,
  그리고 B 의 월 초과수익(대 시장, 세전) 평균 > 0 단측 p < 0.05/2.
- **BETA_ONLY**: (a)·(c)·p 는 충족하지만 (b) 에서 한 구간이라도 대조군에 진다 — 이득이 노출의 값.
- **FAIL**: 그 밖. GOAL_MET 표시는 (a) 가 B·C 모두 +7%p 이상일 때 함께 적는다.
- 보고만: 선택 시대 같은 표, β_sel, 교체 횟수, 국면별 기여.

## 한계(미리 적어 둠)

- 위기 칸을 바꾸는 것은 v1·v2 결과를 보고 떠올린 고치기다. B·C 는 세 번째로 쓰는 자료라 TIMING_HELPS 도 강한 증거가 아니다. 통과하면 다음은 해외(Ken French 지역 자료) 또는 실제 ETF 로 처음 보는 자료 확인.
- 과세 이연 계좌 한도(연금저축·IRP 합산 연 1,800만 원 납입), 5.5% 는 연금소득세 근사, 국내 상장 ETF 로만 가능 — 실제 운용 가능성은 별도 검토.
- 소형 가치 지수(SMALL HiBM)는 초소형주 비중이 커 실제 상품과 다르다.
- 통과도 엔진 채택이 아니다. 전진 원장 후보이며 엔진·계좌 반영은 사용자 확인 뒤 별도 작업이다.
