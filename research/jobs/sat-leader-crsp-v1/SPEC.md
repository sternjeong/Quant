# S2·S3 + 위약: 업종 코어와 연결된 대장주·추종주 (CRSP 1963~2007) (sat-leader-crsp-v1)

사전 등록 2026-10-11. 이 작업의 셀: S2, S2p, S3, S3p. 우선순위 15. CRSP 입력 필요.

세 ETF 시대 연구(sat-pool-v1, sat-leader-v1, sat-follower-v1)와 세 CRSP 연구(…-crsp-v1)는 같은 코드·같은 판정을 쓰고 자료만 다르다. 시도 수 32 는 각 자료 계열의 세 연구 합계다.

## 공통 고정 규칙 (결과를 보기 전에 고정 — 바꾸려면 새 id 로 다시 사전 등록)

코드: `research/jobs/sat-selection-lab/lab.py`(공용), `crsp.py`(CRSP 자료 계층). 새틀라이트 R&D 엔진(`core/satellite_lab.py`)의 시뮬레이터·신호·
`pick_top`·비용 모델을 그대로 쓰고 `core/*.py` 는 고치지 않는다. 주문 경로와 연결되어 있지 않다.

### 질문
새틀라이트 종목 선정 방법을 바꾸면(후보 풀 확대 / 코어와 연결된 섹터 대장주 / 대장주+추종주 / 안전한 추종주 따라잡기), 그리고 보유기간을
{1,3,6,12}개월 중 따로 고르면, 현 규칙(S-SEED-000)과 같은 풀의 무작위 선정보다 나은가. 지금까지 시도는 모두 같은 champion40 풀 안에서 순서만
바꿨다. 이번에는 풀 자체와 선정 방식을 바꾼다.

### 현 규칙 (모든 후보의 선정 규칙, S4 만 예외)
돈치안 20일 돌파로 진입해 고점 대비 15% 하락 시 이탈하는 추세 상태가 '활성'인 종목 중 252거래일 모멘텀 상위 3개, 균등가중,
보유 중 청산 없음, 편도 비용 8bp, 수익은 Adj Close(ETF 시대) 또는 총수익 지수(CRSP), 신호는 리밸런싱일 전 거래일까지의 자료만.

### 전략 (판정 대상 8개 × 보유기간 4개 = 시도 32, 세 연구 합계)
- **S1_70 / S1_100 / S1_150**: 후보 풀 = 그 시점 S&P500 편입 종목 중 그 시점 시가총액 상위 N. 선정은 현 규칙. (S1_100 이 주 후보, 70·150 은 이웃 견고성이지만 모두 같은 판정을 받는다.)
- **S2**: 코어가 리밸런싱일에 비중을 둔 섹터들의 '대장주'(편입 종목 중 그 섹터 시총 최대) = 풀. 선정은 현 규칙. **S2p**(위약): 모든 섹터의 대장주.
- **S3**: 보유 섹터의 대장주 + 추종주 = 풀. 추종주 = 같은 섹터에서 시총이 대장주보다 작고 직전 252거래일 일수익 상관 ≥ 0.6(관측 200일 이상, 리밸런싱일 이전 자료만). **S3p**(위약): 모든 섹터.
- **S4**: 보유 섹터의 추종주(상관 ≥ 0.7) 중 현 규칙과 같은 추세 상태가 활성이고 '안전'(63일 실현 변동성 ≤ 1.5 × 대장주 63일 변동성)인 것에서,
  격차 = 대장주 63거래일 수익률 − 추종주 63거래일 수익률 이 큰 순으로 상위 3(격차 양수 조건 없음). 통제 **S4c** = 같은 후보를 현 규칙(모멘텀)으로 고름(판정하지 않음, 규칙 효과 분리용).
- 코어 연결: ETF 시대는 라이브 코어(core_lab 현 설정 = champion_strategy.run_core_backtest)가 d 에 비중을 둔 섹터 ETF(XLC XLY XLP XLE XLF XLV XLI XLB XLRE XLK XLU)를 섹터(현재 S&P500 표의 GICS)로 잇는다.
  CRSP 시대는 `industry_core`: core-longrun-v1 복제 규칙(FF12 산업 일별 수익, 252거래일 모멘텀 양수 상위 4, 200일 시장 필터)이 d 에 비중을 둔 FF12 산업을 종목의 그 시점 SIC→FF12 와 잇는다.
- **폴백**: 코어가 섹터(산업)를 하나도 안 들면 S2·S3·S4(·S4c)는 그달 기준선 풀의 현 규칙 선정으로 대체(빈도 보고). 섹터를 알아도 선정이 비면 현금(빈 선정 빈도 보고).
- 기준선 B0 = 현 규칙, 기준선 풀(ETF 시대: champion40_pit2 섹터 균형 상위 40 = 라이브 풀 / CRSP: 그 시점 시총 상위 40, 섹터 균형 없음 — 균형 재현을 생략했다), 보유 6개월.
  ETF 시대는 B0 의 2010-07~분할일 IS 연샤프가 등록부 현 규칙 IS 연샤프와 ±0.05 안이어야 하고(아니면 모든 판정 NOT_EVALUABLE) 차이를 보고한다. 등록부를 못 읽으면 UNVERIFIED 로 표시하고 진행.
- 모든 후보에 현 규칙 대비 같은 풀 대조(통제·무작위 중앙값)를 함께 보고하고, 같은 보유기간 기준선 대비 활성 샤프도 보고한다(보유기간 효과 분리).

### 보유기간·구간
- 보유기간 격자 {1,3,6,12}개월(리밸런싱일 = 해당 달들의 첫 거래일: 1개월=매월, 3개월=1·4·7·10월, 6개월=1·7월, 12개월=1월). top_k = 3 균등.
- ETF 시대: 판정 2010-01 → 2024-10-08, 선정 구간(앞 절반) 2010-01 → 2017-05-31, 확인 구간(뒤 절반) 2017-06-01 → 2024-10-08. 2024-10-09 이후는 보고만.
- CRSP: 판정 1963-07-01 → 2007-12-31, 선정 구간 1963-07-01 → 1985-12-31, 확인 구간 1986-01-01 → 2007-12-31. 2008 이후는 보고만.
- 전략마다 보유기간은 **선정 구간에서만** 고른다: 후보 − 기준선(B0 6개월) 일별 활성 수익의 연 정보비율(활성 샤프)이 최대인 보유기간(동률은 짧은 쪽).

### 판정 sat-selection-judge/v1 (전략마다)
PASS_FORWARD_CANDIDATE 는 아래 모두:
(a) 고른 보유기간의 확인 구간 활성 샤프(vs 기준선 B0 6개월) > 0
(b) 확인 구간 샤프 ≥ 같은 풀·같은 보유기간·top_k 3 무작위 선정 500회(시드 고정)의 확인 구간 샤프 95백분위 (S4 의 무작위 풀 = 상관·추세·안전 필터를 통과한 후보)
(c) 인접 보유기간의 확인 구간 활성 샤프도 양수 — 가운데 값이면 양쪽 모두, 격자 끝이면 안쪽으로 가장 가까운 두 격자 중 하나 이상
(d) 확인 구간 최대낙폭이 기준선(B0 6개월)보다 5%p 넘게 나쁘지 않음
(e) 전체 판정 창 활성 수익의 DSR 을 시도 수 32(세 연구 합계)로 계산해 판정 옆에 **출력**(통과 조건 아님)하고, research_power 의 최소 검출 효과를 확인 구간·전체 창 둘 다 출력.
그 밖: `classify_fail` 로 FAIL 또는 FAIL_UNDERPOWERED. 후보가 기준선과 매일 같으면(`noop_guard`) NOT_EVALUABLE.
PASS 는 '전진 원장에 올릴 후보'일 뿐이다(`core/forward_tournament_v2.py` 후보는 동결 — 이 연구가 바꾸지 않는다). 엔진 반영은 사용자 확인 뒤 별도 작업.

## CRSP 입력 계약 (고정)

경로 `data/research_inputs/crsp_sp500/`. 없거나 열이 모자라면 작업은 코드 0 으로 끝나며 판정은 `NOT_EVALUABLE_DATA`, REPORT.md 에 필요한 파일이 적힌다.

```
daily.csv    permno,date,prc,ret,vol,shrout     crsp.dsf        permno ∈ dsp500list 에 한 번이라도 나온 종목, date ≥ 1961-01-01
names.csv    permno,namedt,nameendt,siccd,exchcd,shrcd   crsp.dsenames   위 종목 전체 이름 구간
delists.csv  permno,date,dlret,dlstcd           crsp.dsedelist  위 종목 전체(date = dlstdt, dlret 빈 행 포함)
sp500.csv    permno,start,ending                crsp.dsp500list 전체(ending 빈칸 = 현재 편입)
```
헤더 소문자 그대로, 날짜 YYYY-MM-DD 또는 YYYYMMDD. 처리 규칙: 시가총액 = |prc|×shrout×1000(리밸런싱일 전 거래일), 총수익 지수 = 누적곱(1+ret),
dlret 은 −1~+1 일 때만 폐지일(또는 그 이전 마지막 기록일) 수익에 (1+ret)(1+dlret)−1 로 합침(−55/−66/−88/−99·빈 값은 미적용, 건수 보고),
ret 이 숫자가 아니거나 −1 미만이면 그날 수익 0, 구성종목 = start ≤ 전 거래일 ≤ ending, 섹터 = 그 시점 siccd → Fama-French 12 산업(Ken French Siccodes12 공개 범위를 코드에 고정), 없으면 Other.
