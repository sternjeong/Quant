## 사건·층

공용 SPEC 과 같다(판정 = 미국 시장 사건). 판정 층 A·B·**C(2008-01~2024-09)**, 2024-10 이후 보고만.
**v1 관례와 다른 점**: v1 은 A·B 만 판정했다. 이 연구는 검정력 때문에 C 를 판정에 넣는다. C 의 사건들은 이미 crash-cycle-model-v1 보고서에서 본 것이다 — 그래서 A·B·C 각 층의 평균이 모두 양수여야 통과한다.

업종 사건: 열 k 마다 첫 유효일 f 부터 I_k = (1 + ind49[k][f:]).cumprod()(시작 뒤 결측일 0), `lab.market_context(I_k, "IND:k")` — v1 정의 그대로(252일 고점 −15%, −5% 위로 끝, 같은 고점 병합).
이력이 300일 미만인 열은 사건을 만들 수 없어 뺀다(252일 고점 정의상 그 전에는 사건이 생길 수 없음 — 구현 메모).

## 특징 (모두 t0 종가까지)

| 코드 | 업종 사건(그 업종 자기 자료) | 시장 사건(시장 자료) |
|---|---|---|
| DD0 | dd0 | dd0 |
| SPEED | ln(max(t0 − tP, 1)) | v1 특징 SPEED(같은 식) |
| VOLRATIO | volratio(logret(I_k), t0) | volratio(logret(L), t0) |
| RUNUP | ln(I_k[tP] / I_k[tP − 504])(tP < 504 이면 결측) | v1 특징 RUNUP(같은 식) |

## 방법

1. 시장 사건 i(D = 발생일): C(i) = {업종 사건 r : t0_r < D, lb_label(r, D) 있음}(라벨 1 = 252거래일 안 회복 못 함, D 에 알 수 있는 것만),
   `fit_ridge_logit(X_C, y_C, λ = 4)`(업종으로 표준화). 'fit 가능'이 아니면 미적합 → 두 판정 모두에서 빠짐(n_unfit).
2. 모델 1·2(XFER): 4.8 절 2·3단계 — 풀 = 시장 T1·m2_pool, 특징 = 시장 특징. 기울기·표준화는 업종에서, 기준 확률 π·중심 ē 는 시장 풀에서(`p_center`).
   p_center 가 None(시장 풀 라벨이 한 갈래뿐)이면 미적합.
3. p_lb(예외): p_center(fit, x_i, 시장 라벨 집합 특징, 라벨), 시장 라벨 집합 = {미국 사건 j : t0_j < D, lb_label(j, D) 있음}(업종 기준 확률이 아니라 시장 기준 확률).
4. 쌍 차이 d1 = 핀볼(BASE) − 핀볼(XFER)(깊이 확정), d2 = 브라이어(BASE) − 브라이어(XFER)(자료 안 회복). BASE = v1 발생일 기준선.

## 판정

| 키 | 비교 | 점수 | 통과 라벨 |
|---|---|---|---|
| XFER_M1 | XFER vs BASE | 평균 핀볼 | BEATS_BASELINE |
| XFER_M2 | XFER vs BASE | 브라이어(1·2·3·5년) | BEATS_BASELINE |

`lab.judge_us`: A ≥ 4·B ≥ 5·C ≥ 4·합친 ≥ 15, 무효 가드, A·B·C 평균 모두 양수 + 합친 한쪽 부호 뒤집기 p < α = 0.05/15. 그 밖 FAIL(세 평균 양수면 FAIL_UNDERPOWERED),
표본 미달·무효 → NOT_EVALUABLE. 족 15개 공통 α.

업종 사건은 1930년대에 이미 수백 건이라 1946 이후 모든 시장 사건에서 적합 가능 → 예상 n A 5·B 9·C 7 = 21. 필요 효과 0.66 sd.

## 편향 방지

v1 에서 시장 수준 SPEED·RUNUP 커널이 실패한 것을 보았다 — 통과 쪽 편향은 없다. 기울기는 업종 사건으로만 배우고 시장 사건은 중심·기준 확률에만 쓴다. 업종 급락은 이 질문에 처음 쓴다.
