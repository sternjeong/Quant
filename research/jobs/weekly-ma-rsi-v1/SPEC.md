# weekly-ma-rsi-v1 — 주봉 20주선·RSI 과매도 매매, 적립식 세후 대 SPY (사전 등록 2026-10-18)

사용자 요청: 주봉 기준 20주 이동평균선과 RSI 과매도를 이용한 매매 기법을 실험하고, 곁가지로 QQQ 도 확인.
사용자 목표(장기·끝없이 운영, 세후로 SPY 이기기)에 맞춰 contrib-reval-sector-v1 과 같은 적립식 다중 시작일 틀로 잰다.

## 자료
- yfinance SPY·QQQ·BIL 일별 종가/조정 종가(1998-12 부터), 원/달러 tax_fx.usdkrw_series.
- 주봉 = 각 주(월~금) 마지막 거래일의 조정 종가. 신호는 그 종가로 정하고 다음 거래일 종가에 매매.
- 밖에 있을 때 BIL, 2007-05 BIL 상장 전은 이자 없는 달러 현금.

## 전략 (X ∈ {SPY, QQQ})
- X_MA20: 주 종가 > 20주 단순 이동평균이면 X 100%, 아니면 BIL.
- X_RSI: RSI(14주, Wilder) < 30 이면 매수, RSI ≥ 70 이면 매도. 처음엔 밖.
- X_MA20RSI: 20주선 위면 보유. 20주선 아래라도 RSI < 30 이 나오면 매수해 RSI ≥ 50 회복까지 보유.

## 평가
- 계좌: tax_fx 카카오 기본값(수수료 0.1%, 환전 우대 95%, 양도세 22%·공제 250만 원, 5월 납부), 적립 underweight_first.
- 시나리오: B 1,000만 원 + 월 15만 원(판정), A 1,000만 원, C 300만 원 + 월 15만 원, B10 1억 + 월 150만 원(보고).
- 구간: 2000-01 부터 매달 시작하는 10년(판정·모든 시나리오), 5년(B 만, 보고). 구간 끝 ≤ 2024-09-30 만 판정.
- 기준: SPY 그냥 보유(같은 날 같은 돈). 끝에 모두 판다고 보고 미납 세금을 뺀 금액·IRR 로 비교.

## 판정 (6개 전략 각각, 시나리오 B·10년·대 SPY)
CONTRIB_BEATS_SPY ⇔ ① 이긴 구간 비율 ≥ 70% ② IRR 차이 중앙값 ≥ +0.5%p ③ IRR 차이 10분위 ≥ −1.5%p
④ 시간가중 MDD 중앙값이 SPY 보다 5%p 넘게 나쁘지 않음. 아니면 research_power.classify_fail(시도 6, 24.7년) → FAIL / FAIL_UNDERPOWERED.
SPY 와 매일 같으면 NOT_EVALUABLE.

## 보고만
- QQQ 그냥 보유 대 SPY (QQQ 는 사후 선택이라 판정 안 함).
- QQQ_* 대 QQQ 그냥 보유 (기법이 QQQ 자체를 낫게 하나) — 같은 규칙 충족 여부만 표시.
- 한 계좌 전체 기간(2000-01 ~ 2024-09, B): 시장 체류 비율, 매매 전환 수, 세금, 수수료.

규칙은 결과를 보기 전에 고정했다. 바꾸려면 새 id 로 다시 등록한다. 통과해도 엔진은 바뀌지 않는다(사용자 확인 뒤 별도 작업).
