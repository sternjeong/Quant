# 거시경제 이벤트 스터디 — 전체 로드맵

## 목표
개별 트레이딩 전략을 백테스트하는 게 아니라, "특정 사건이 벌어졌을 때 시장이 어떻게 반응했는가"라는
패턴을 여러 종류의 사건에 걸쳐 찾아내고, 경제학 배경지식 없이도 이해할 수 있는 형태로 정리한다.
Kostolany 리포트와는 완전히 별개의 연구 스레드 — 필요하면 나중에 하나로 합칠 수도 있지만 지금은
각 주제별로 독립된 짧은 리포트(아티팩트)로 쌓아간다.

FRED에서 발표일을 정확히 자동으로 뽑아낼 수 있어, 사람이 캘린더를 손으로 옮겨적을 필요가 없다.
