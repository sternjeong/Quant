# 2026-10-01부터 챔피언 전략을 따랐다면

사용자 최종 결정(2026-10-13): 시작일은 2026-10-01 고정. 종료일은 화면을 여는 한국 날짜, 결과 기준은 확보된 미국 거래일 종가. 초기 금액은 기존 성과 화면의 달러 금액 입력을 사용한다.

챔피언 성과 B를 현 전략의 가상 추종 결과로 교체한다. 구형 3개월 상위5 원장 수익은 이 결과에 섞지 않는다. 기존 원장과 paper 계좌 데이터는 보존한다.

- 코어: 기존 `run_core_backtest`의 월 첫 거래일 선정·시장필터·단기국채(BIL)·비용 관례를 그대로 사용한다. 전체 비중 85%.
- 새틀라이트: 기존 주 추천의 `_pick_satellite_at_date`에 시작일을 넘겨 당시 정보로 최대 3개 선정. 매수일부터 6개월마다 다음 실제 거래일에 재선정. 1월·7월의 과거 목록을 가져오지 않는다. 전체 비중 15%, 후보가 없으면 해당 몫은 수익 0 현금이며 코어 100%로 바꾸지 않는다.
- 신호는 선정일 이전 가격, 체결은 선정일 종가, 다음 거래일부터 수익과 거래비용을 반영하는 기존 엔진 관례. 코어 편도 3bp, 새틀라이트 편도 8bp. 코어는 배당 반영 가격, 새틀라이트는 기존 엔진의 Close 가격. 세금·추가 슬리피지 제외. SPY는 비용 없는 매수보유 참고선.
- 표시: 시작일·실제 가격 기준일·초기/최종 금액·손익·수익률·최대낙폭·SPY 비교·가상 자산곡선·초기/마지막 목표 비중·거래/비중 변경 기록. 금액은 배수 결과를 환산하므로 초기 금액 변경으로 계산을 반복하지 않는다.
- 사용자 포트폴리오 참고선(2026-10-13 추가): `portfolio_holdings`의 현재 보유분만 읽고, 각 기록의 매입일부터 현 수량을 보유했다고 놓아 일별 종가로 평가한다. 새 매입원금은 외부 유입으로 빼는 시간가중 곡선을 첫 보유일 1.0으로 시작한다. B의 한 그래프에 세 선의 달러 금액 대신 시작 대비 수익률(%)을 그린다. 기본 보기에서는 챔피언·SPY는 10월 1일에 0%, 현재 보유분은 첫 보유일에 0%다. '내 첫 매입일부터 같은 기간'으로 바꾸면 챔피언·SPY도 그날 0%로 맞춘다. 미실현손익은 현 보유분의 매입원금과 마지막 종가 평가액 차액이다. 과거 매도·수량 변경·현금 입출금 이력이 없어 계좌 전체 실적이 아니며, 보유가격 누락은 곡선 생성을 중단하고 이유를 보여 준다.
- 종목별 기여(2026-10-30 추가): 챔피언은 코어·새틀라이트의 일별 순수익 기여에 전일 가상 자산 배수를 곱한 `pnl_x`를 캐시에 저장한다. 그래프에서 선택한 시작일 **다음** 거래일부터 합산해 시작일 배수로 나누고 화면의 가상 초기 금액을 곱한다. 따라서 종목별 가상 손익 합계는 같은 기간 챔피언 수익률 × 가상 초기 금액과 일치한다. 비용과 WBD 현금 인수가 반영되고, 이미 끝난 거래도 포함한다. 내 보유분은 지금 남아 있는 매입 기록별 `현재 수량 × (마지막 종가 − 매입가)`를 티커별로 합친 미실현손익과, 매일 보유평가 변화에서 그날 새 매입원금을 뺀 기여를 연결해 보라색 수익률의 %p 기여를 표시한다. 첫 매입일의 종가와 실제 매입가 차이는 시작일 0% 정규화 때문에 보라색 곡선 기여에 들어가지 않지만 미실현손익에는 들어간다.
- 비교 기준: 그래프는 **금액이 아니라 시간가중 수익률**이다. 외부에서 $1,000을 추가해 내 계좌가 $10,000→$11,000이 되어도 그 $1,000 자체는 수익이 아니므로 보라선 수익률에서 제외한다. SPY·챔피언은 같은 기간의 % 수익률로 비교한다. 달러 자산 경로를 비교하려면 실제 계좌 밖에서 들어오고 나간 금액만 같은 날짜에 두 가상 계좌에 적용해야 한다. 계좌 내부 A 매도→B 매수는 외부 흐름 0이다. 현재 DB에는 매도·수량 변경·입출금 장부가 없어 실제 계좌 전체의 달러 경로와 동일 현금흐름 가상 비교를 만들어 표시하지 않는다. 현재 보라선의 새 매입원금은 모두 외부 유입으로 가정하므로 매도대금 재투자가 있었다면 실제 TWR과 다를 수 있다.
- 긴 계산은 명시적 버튼에서 VM의 앱 백그라운드 작업으로 수행하고 결과 캐시를 사용한다. 기존 새벽 미리 계산 잡에도 연결해 매일 갱신한다. 화면 진입만으로 계산하지 않는다. 다른 기간의 작업 결과를 이 구간으로 표시하지 않는다.
- WBD는 2026-10-05 마지막 거래 뒤 10-06 현금 인수됐다. [Nasdaq 기업행동 공시 ECA2026-710](https://www.nasdaqtrader.com/TraderNews.aspx?id=ECA2026-710)의 주당 $31.01666668을 10-06 수령하고 다음 새틀라이트 재선정 전까지 현금으로 평가한다. 이후 재선정 때 이미 현금인 WBD에 매도 수수료를 다시 붙이지 않는다. 화면에는 기업행동·현금 배분·거래 이벤트를 따로 표시한다. 이는 임의의 가격 대체가 아니라 확인된 현금 인수에만 적용한다.
- 다른 보유 종목 가격 누락, 시장 가격 부재, 새틀라이트 후보 데이터 부재는 계산 실패로 표시한다. 이미 보유한 종목의 누락을 가격 정체/수익 0으로 처리하지 않는다.

이 기능은 현 규칙의 지정 구간 표시 도구이며 가설 검정·새 전략 비교 연구가 아니다. 단위 검증은 합성 데이터만 사용한다. 새 전략 채택 판정은 하지 않는다. 주문·추천·스케줄러 규칙 및 과거 원장은 변경하지 않는다. 과거 시점의 공식 추천 저장본이 아니라 현재 규칙으로 재구성한 가상 결과이며, 기존 후보군의 생존편향 및 데이터 한계를 함께 표시한다.
