# 2026-10-01부터 챔피언 전략을 따랐다면

사용자 최종 결정(2026-10-13): 시작일은 2026-10-01 고정. 종료일은 화면을 여는 한국 날짜, 결과 기준은 확보된 미국 거래일 종가. 초기 금액은 기존 성과 화면의 달러 금액 입력을 사용한다.

챔피언 성과 B를 현 전략의 가상 추종 결과로 교체한다. 구형 3개월 상위5 원장 수익은 이 결과에 섞지 않는다. 기존 원장과 paper 계좌 데이터는 보존한다.

- 코어: 기존 `run_core_backtest`의 월 첫 거래일 선정·시장필터·단기국채(BIL)·비용 관례를 그대로 사용한다. 전체 비중 85%.
- 새틀라이트: 기존 주 추천의 `_pick_satellite_at_date`에 시작일을 넘겨 당시 정보로 최대 3개 선정. 매수일부터 6개월마다 다음 실제 거래일에 재선정. 1월·7월의 과거 목록을 가져오지 않는다. 전체 비중 15%, 후보가 없으면 해당 몫은 수익 0 현금이며 코어 100%로 바꾸지 않는다.
- 신호는 선정일 이전 가격, 체결은 선정일 종가, 다음 거래일부터 수익과 거래비용을 반영하는 기존 엔진 관례. 코어 편도 3bp, 새틀라이트 편도 8bp. 코어는 배당 반영 가격, 새틀라이트는 기존 엔진의 Close 가격. 세금·추가 슬리피지 제외. SPY는 비용 없는 매수보유 참고선.
- 표시: 시작일·실제 가격 기준일·초기/최종 금액·손익·수익률·최대낙폭·SPY 비교·가상 자산곡선·초기/마지막 목표 비중·거래/비중 변경 기록. 금액은 배수 결과를 환산하므로 초기 금액 변경으로 계산을 반복하지 않는다.
- 긴 계산은 명시적 버튼에서 VM의 앱 백그라운드 작업으로 수행하고 결과 캐시를 사용한다. 기존 새벽 미리 계산 잡에도 연결해 매일 갱신한다. 화면 진입만으로 계산하지 않는다. 다른 기간의 작업 결과를 이 구간으로 표시하지 않는다.
- 보유 종목 가격 누락, 시장 가격 부재, 새틀라이트 후보 데이터 부재는 계산 실패로 표시한다. 이미 보유한 종목의 누락을 가격 정체/수익 0으로 처리하지 않는다.

이 기능은 현 규칙의 지정 구간 표시 도구이며 가설 검정·새 전략 비교 연구가 아니다. 단위 검증은 합성 데이터만 사용한다. 새 전략 채택 판정은 하지 않는다. 주문·추천·스케줄러 규칙 및 과거 원장은 변경하지 않는다. 과거 시점의 공식 추천 저장본이 아니라 현재 규칙으로 재구성한 가상 결과이며, 기존 후보군의 생존편향 및 데이터 한계를 함께 표시한다.
