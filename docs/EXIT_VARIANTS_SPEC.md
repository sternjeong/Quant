# 청산 규칙 변형 비교 설계 (후보 원장 확장)

상태: **사전 등록(2026-09-26, 코드·결과 계산 전에 커밋)**. 관측·연구 전용이며 주문 경로와 연결하지 않는다. 스케줄러에도 연결하지 않는다(함수만 제공). 이 문서와 결과의 어떤 수치도 성과·승률 개선을 주장하지 않으며, 결과는 과거 관측일 뿐 미래 성과를 보장하지 않는다.

## 왜

후보 shadow 원장(`core/candidate_ledger.py`, [CANDIDATE_LEDGER_SPEC.md](./CANDIDATE_LEDGER_SPEC.md))은 모든 후보를 "다음 시가 진입 → 20거래일 뒤 시가 청산" 하나로만 평가한다. 실제 성과는 손실을 얼마나 작게 끊느냐(청산 규칙)에 크게 좌우되므로, **같은 후보·같은 진입**에서 청산 규칙만 바꾼 결과를 원장과 같은 판정 틀로 비교한다. 보는 값은 승률만이 아니라 비용 후 기대값·놓친 기회(보류·거절 후보 평균)·최대 손실·분위수다.

## 사전 고정 원칙

- 변형과 파라미터는 **결과를 보기 전에** 이 문서와 코드 상수(`core/exit_variants.py`)로 고정한다. 결과를 본 뒤 값을 바꾸거나 변형을 추가·삭제하면 그 결과는 새 사전 등록이 아니라 **탐색 결과**로만 취급하고, 이 문서에 변경 이력과 사유를 남긴다.
- 파라미터는 흔히 쓰이는 어림값이거나(8%, 10%) 이미 운용 중인 위성 전략의 값을 그대로 가져온 것이며(15%), 이 데이터로 최적화하지 않았다.
- 새 통계 규칙을 만들지 않는다. 지표·신뢰구간·판정은 모두 `candidate_ledger.evaluate_selection` / `decide_verdict`를 그대로 쓴다.

## 사전 고정 변형 (4개)

| 이름 | 규칙 | 파라미터 | 근거 |
|---|---|---|---|
| `baseline_20d` | 원장과 동일: 진입 세션 + 20거래일 뒤 세션 시가 청산 | horizon 20 | 원장 결과와 숫자가 정확히 같아야 한다(회귀 기준) |
| `fixed_stop_8` | 고정 손절 + 20거래일 상한 | 종가 ≤ 진입가 × (1 − 0.08) | 흔한 어림값, 최적화 안 함 |
| `trailing_10` | 추적 손절 + 20거래일 상한 | 종가 ≤ 진입 이후 최고 종가 × (1 − 0.10) | 흔한 어림값, 최적화 안 함 |
| `satellite_trailing_15` | 위성 전략의 트레일링 스탑 + 20거래일 상한 | 종가 ≤ 진입 이후 최고 종가 × (1 − 0.15) | `core/champion_strategy.py`의 `SATELLITE_DONCHIAN_STOP_PCT = 0.15`와 `donchian_trailing_stop_positions` 규칙(고점 = 진입일 종가부터 당일 종가까지의 최고 종가, `c <= peak*(1-stop)`) 그대로. 원 전략은 시간 상한이 없으나 원장 비교를 위해 20거래일 상한을 둔다. 원 상수가 바뀌면 테스트가 실패한다 |

## 체결 가정 (미래 정보 없음)

- 진입: 원장과 같다(`decision_cutoff` 이후 첫 세션 시가. `compute_outcome`이 정한 진입 세션·가격을 그대로 쓴다).
- 손절 판단: **일봉 종가**로만 한다. 확인 대상은 진입 세션부터 상한 청산 전날까지의 종가(진입일 종가 포함).
- 손절 체결: 판단한 날의 **다음 거래일 시가**. 장중 저가·손절선 가격으로 체결됐다고 가정하지 않는다. 갭 하락이면 그 시가 그대로(손절선보다 훨씬 낮을 수 있다).
- 다음 거래일에 종목 시가가 없으면 그 뒤 첫 유효 시가(늦어도 상한 청산 세션)에서 체결하고 `detail.stop_fill_delayed`로 남긴다. 종가가 없는 날은 손절 판단을 하지 않는다(값을 지어내지 않음).
- 추적 손절의 최고 종가는 진입일 종가에서 시작해 매일 갱신하며, 당일 종가를 먼저 반영한 뒤 비교한다(위성 규칙과 동일).
- 상한: 손절이 없으면 원장과 같은 20거래일 뒤 세션 시가. 마지막 확인일(상한 전날)에 손절이 나면 상한 세션 시가로 청산되며 사유는 `stop`으로 남긴다.
- 거래일력은 원장과 같은 SPY 세션. 비용은 원장과 같은 편도 5/10/25bp(`COST_SCENARIOS_BPS`)를 모두 계산하고 주 검정은 10bp.
- 주 대상은 원장과 같은 `net_excess_spy` = 비용 후 수익 − **같은 진입·실제 청산 세션** 시가 기준 SPY 수익. 섹터 잔차는 계산하지 않는다.

## 결측·대기 처리

- 모든 변형은 원장 기준선과 **같은 모집단**에서 비교한다. 기준선이 `pending`/`missing`이면 모든 변형도 같은 상태·같은 사유(`no_entry_bar`, `data_ended_before_exit`, `horizon_not_reached` 등)를 그대로 가진다. 손절 변형이 상장폐지 전에 빠져나올 수 있었더라도 결과로 세지 않는다(변형마다 모집단이 달라지면 비교가 왜곡되기 때문). 보수적 선택이며 한계에 적는다.
- 기준선이 `final`인데 종가 열이 전혀 없으면 손절 변형은 `missing`(`close_unavailable_for_stop`).

## 비교와 다중비교 처리

- 변형마다 `evaluate_selection`(주 대상·주 비용·주 horizon 20)을 돌려 채택 그룹의 비용 후 기대값·승률·손익비·최대 손실·분위수, 놓친 기회(보류·거절 평균), 판정을 낸다. 기준선 대비 차이는 표로 보인다.
- **다중비교:** 기준선이 아닌 변형이 3개이므로 이들은 Bonferroni 보정 α = 0.05 / 3으로 신뢰구간을 계산하고, 판정 옆에 항상 **"탐색 결과"** 라벨을 붙인다. 기준선은 원장의 사전 등록 검정이라 원장과 같은 α = 0.05.
- **짝지은 차이:** 같은 후보에서 (변형 − 기준선) 주 대상 값의 차이를 `evaluate_selection`에 넣어 채택 그룹 평균 차이의 군집 부트스트랩 신뢰구간(보정 α)을 본다. 대상이 주 대상이 아니므로 `decide_verdict`가 항상 '미입증'을 낸다 — 설명용 수치일 뿐 판정이 아니다.
- 원장 규칙 그대로: 표본 부족·PIT 미인증·결측률 과다·신뢰구간이 0 포함이면 '미입증'. 검토 대상이 나와도 자동 채택이 아니다.

## 저장

새 테이블 없음. 원장 테이블(`candidate_decisions`, `candidate_outcomes`)과 가격 캐시(`core.market_data`)만 읽고 계산한다. 보고서 `data/reports/exit_variants_YYYY-MM-DD.{md,json}`가 결과 기록이며, 같은 날 다시 만들면 같은 파일을 덮어쓴다(부트스트랩 시드 고정 → 같은 입력이면 같은 결과).

## 보고서와 배선 (미배선)

`core.exit_variants.write_exit_variants_report(out_dir=None) -> dict`. 스케줄러에는 연결하지 않는다. 주간 연구 보고서 흐름에 붙이려면 주간 잡에서 `update_forward_outcomes` 이후에 이 함수를 try/except로 한 번 부르면 된다(실패해도 다른 잡을 막지 않게).

## 한계

- 일봉 종가 판단 + 다음 시가 체결이라 장중 손절 주문보다 손실이 커질 수 있다(보수적). 실제 손절 주문의 체결은 다르다.
- 기준선이 결측인 후보(상장폐지 등)는 모든 변형에서 제외되어, 손절이 상장폐지 손실을 막았을 경우를 반영하지 못한다.
- 변형이 20거래일 상한 안에서만 다르므로 위성 전략의 원래 청산(상한 없음)과는 다르다.
- 원장의 한계(배당 미반영, 시가 체결, SPY 거래일력, 부트스트랩 근사)를 그대로 물려받는다.
