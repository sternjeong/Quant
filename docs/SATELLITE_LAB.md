# 새틀라이트 R&D 센터 — 설계와 사전 고정 판정 규칙

작성 2026-10-02. 코드: `core/satellite_lab.py`(엔진·심판·등록부), `scripts/satellite_lab_worker.py`(계산기),
`core/agent_batch.py`의 새틀라이트 트랙(sat_designer·sat_critic), `hub/satellite_lab_page.py`(관제 센터 화면).

## 1. 무엇을 묻나

"이 선정 규칙이 현 챔피언 새틀라이트 규칙(S-SEED-000)보다, 그리고 같은 후보 풀에서 무작위로 고른 것보다 종목을 더 잘 고르는가?"
계기: 2026-07-01 반기 선정(CAT·GEV·JNJ)이 3개월 −9%로 같은 풀 평균(−5%)과 SPY(+2%)에 뒤졌고, 리서치 감사에서
새틀라이트 선정 방식·포함 여부가 모두 weak 등급이었다. 한 구간으로는 판단할 수 없으므로 같은 질문을 체계적으로 반복 시험한다.

## 2. 공정한 비교 (같은 조건)

- 기간 2010-01-01 ~ 계산일. 리밸런싱일 d = 보유기간에 맞는 달의 첫 거래일(6개월: 1·7월, 3개월: 1·4·7·10월, 1개월: 매월).
- 신호는 d 전날 종가까지, d 전 730달력일 일봉만 본다(현 규칙과 같은 창). d 종가에 동일가중 매수, 다음 리밸런싱일 종가까지 표류 보유.
- 선택적 트레일링스탑: 진입 후 고점 대비 stop_pct 하락한 날 종가 매도 → 다음 리밸런싱까지 현금.
- 비용: 편도 8bp × 회전율(이어서 보유하면 비용 없음), 스탑 청산도 편도 8bp. 배당·세금·슬리피지 없음.
- 후보 풀: champion40(현 규칙과 같은 sample_universe(n=40, 그 시점 편입·그 시점 시총), 반기 갱신) 또는 sp500_pit(그 시점 편입 전체). 코어 17자산·SPY 제외.
- 무작위 기준선: 같은 구조(풀·종목 수·보유기간·청산)로 리밸런싱일마다 이력 260거래일 이상 종목 중 무작위 추출, 200회, 시드 20261002.
- 현 규칙 재현 검증: `tests/test_satellite_lab.py::test_incumbent_seed_reproduces_champion_pick` 가 랩의 S-SEED-000 선정이
  `champion_strategy._pick_satellite_at_date` 와 날짜마다 같음을 확인한다.

## 3. 판정 규칙 sat-judge/v1 (결과를 보기 전에 고정 — 바꾸려면 새 버전으로 재등록)

**v2(2026-10-05):** 관문은 아래와 같고, 수익 측정만 배당 포함 조정 가격(Adj Close)으로 바꿨다(v1 은 Close 라 배당주가 불리했다). 신호는 그대로 가격(Close)을 본다. v1 결과는 `data/satellite_lab/registry_sat-judge_v1.json` 에 보관하고 모든 아이디어를 v2 로 다시 심판한다. 누적 시도 수는 이어서 센다.

표본 분리: 마지막 2년(OOS)은 떼어 두고 파라미터는 앞 구간(IS, 최소 3년)에서 IS 연샤프 최대로 고른다. 모두 통과해야 PASS.

| 관문 | 기준 |
|---|---|
| G1 우연보다 나음 | IS 연샤프가 같은 구조 무작위 분포의 95백분위 이상 |
| G2 현 규칙보다 나음(다중검정 보정) | IS 일별 초과수익(후보 − 현 규칙)의 Deflated Sharpe ≥ 0.95. 시도 수 = 등록부 누적 시도(모든 파라미터 조합, 줄지 않음), 분산 = 지금까지 판정된 시도들의 초과 샤프(2개 미만이면 연 0.5 가정) |
| G3 떼어 둔 2년 | OOS 연샤프 > 현 규칙 OOS 연샤프, 그리고 OOS 무작위 분포 50백분위 이상 |
| G4 파라미터 강건 | 숫자 파라미터를 하나씩 ×0.5·×1.5 로 바꾼 조합(최대 6개)의 IS 초과 연샤프가 모두 양수, 중앙값 ≥ 선택값의 50% (숫자 파라미터 없으면 생략) |
| G5 위험·표본 | IS 최대낙폭이 현 규칙보다 10%p 넘게 나쁘지 않음, IS 리밸런싱 12회 이상 |

PASS = '사람 검토 대기'. 챔피언(엔진) 반영은 사용자 확인 뒤 별도 작업으로 한다. 판정은 등록부에 그대로 남고 다시 매기지 않는다.

## 4. 아이디어와 시도 수 관리

- 시작 목록(저장소, 사람이 작성): S-SEED-000 현 규칙(기준선, 시도 수 0) + 001 S&P500 전체 풀, 002 3개월 보유, 003 보유 중 15% 손절,
  004 6종목, 005 12-1 모멘텀, 006 52주 신고가 근접, 007 변동성 조정 모멘텀, 008 꾸준한 상승(frog-in-the-pan), 009 저변동 추세.
- 야간 에이전트(03:00 배치): sat_designer 가 아이디어 하나(spec.json·signal.py·test_signal.py) → 결정론 검사(pytest + 합성 데이터 실행 +
  리밸런싱일 이후 가격을 바꿔도 선정이 같은지) → sat_critic(수익률 안 봄) → 배치가 `data/satellite_lab/agent/<id>.json` 에 승인 해시 기록
  → 계산기가 동결. 재작업 최대 3회, 동시 진행 2개, 에이전트 동결 주 6건 상한. 계약: `research/agent_prompts/_sat_contract.md`.
- 동결된 스펙·코드는 바꿀 수 없다(해시 기록). 개선안은 parent 를 지정한 새 id.
