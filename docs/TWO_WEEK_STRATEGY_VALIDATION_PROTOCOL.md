# 14일 전략 검증 프로토콜

목적은 최고 과거수익률 전략을 찾는 것이 아니라, 사전에 고정한 후보 중 실계좌 paper trading으로
넘길 근거가 있는 전략이 있는지 판정하는 것이다. 결과가 기준을 통과하지 않으면 선택 수는 0개다.

## 고정 후보와 기준선

후보는 다음 여섯 개로 고정한다. 기간 중 신호·파라미터·유니버스를 추가하거나 바꾸지 않는다.

| ID | 규칙 |
| --- | --- |
| S1 | 17 ETF, 12개월 원시 상대모멘텀 상위 4개, 월간 |
| S2 | S1과 같지만 최근 1개월을 제외한 12-1개월 모멘텀 |
| S3 | 17 ETF 각각의 12개월 절대모멘텀 양수분만 동일가중, 음수분은 현금 |
| S4 | SPY/EFA/IEF/GLD/DBC의 10개월 SMA 추세배분, 월간 |
| S5 | 5 자산군 ETF의 절대모멘텀 양수분 중 상대모멘텀 상위 3개, 월간 |
| S6 | S1 85% + point-in-time 돈치안 새틀라이트 15%, 코어 월간/새틀라이트 반기 |

기준선은 SPY 매수보유, 60/40(SPY/IEF), 후보 유니버스 동일가중으로 고정한다.

## 데이터와 실행 가정

1. 신호는 거래일 종가로 계산하고 주문은 반드시 다음 거래일 시가에 체결한다.
2. 조정주가와 시가 데이터의 출처·조회시각·해시를 manifest에 기록한다.
3. 실제 상장 ETF만 쓰는 주 표본과 장기 프록시 표본을 분리한다. XLC가 포함된 현재 유니버스의
   실제 공통 표본은 2018년 이후라 장기 결론의 단독 근거가 될 수 없다. 장기 표본은 사전에
   고정한 XLC→VOX 프록시와 공통 시작일(2007년 이후)을 쓰며, 결과를 "프록시"로 표기한다.
4. S6은 point-in-time 유니버스가 존재하는 기간만 독립 평가한다. S1과 직접 비교할 때는 두
   전략의 공통 일자만 사용한다.
5. 편도 비용은 5bp, 10bp, 25bp 세 경우로 모두 계산한다. 스프레드·수수료·부분체결은 paper
   기간에서 별도로 실측한다.

## 사전 등록 선택 게이트

모든 하드 게이트를 통과해야 후보로 남는다.

- 데이터 누수, 미래 유니버스, 동일일 종가 체결, 미설명 결측 처리: 즉시 탈락.
- 25bp 편도 비용에서 주문이 정의되지 않거나 성과가 기준선보다 일관되게 열세: 탈락.
- 세 표본외 구간 중 두 구간 이상에서 SPY 또는 60/40 대비 비용 후 Calmar가 열세: 탈락.
- PBO가 0.20 초과 또는 Deflated Sharpe Ratio가 0.95 미만: "탐색"으로만 보관하고 paper trading
  후보에서는 제외.
- S6은 S1보다 두 개 이상의 표본외 구간에서 개선되고 부트스트랩 개선 확률이 60% 이상일 때만
  S1을 대체할 수 있다. 그렇지 않으면 새틀라이트는 paper shadow sleeve로만 유지한다.

남은 후보 중 순위는 비용 후 Calmar, bootstrap 중앙값, 최악 3개월, turnover 순서로 매긴다.
최종 두 전략은 월 수익률 상관 0.75 미만이어야 하며, 조건을 만족하지 않으면 하나만 또는 0개를
선택한다.

## VM 운용

quant-vm은 2코어이므로 감독 서비스는 동시에 하나의 Claude만 실행하고(2026-09-19부터 Codex 대신 Claude
CLI로 전환), 완료·한도·오류를 감시하는
서비스 자체는 상시 유지한다. 다음 감독 실행은 기본 4시간 뒤이며, 같은 결정론적 백테스트를 반복하지
않고 아직 끝나지 않은 산출물 하나만 실행한다. 기존 Streamlit·scheduler 및 이미 활성화된 별도
리서치 타이머는 이 프로토콜이 임의로 중지하지 않는다. 매 작업 후 manifest, 로그, 결과 해시를 저장하고
Telegram에는 진행률·실패·중간 순위만 보낸다. 전략 규칙 변경은 14일 종료 전 금지한다.

운영 상태는 git 밖의 `.experiment-control/state.json`, 일시정지·중지는
`.experiment-control/control.json`에 기록한다. 각 Day가 모든 통과 조건을 충족했을 때만
`docs/experiment_validation/PROGRESS.md`에 `DAY_N_COMPLETE` 표식을 기록한다. 감독기는 이 표식만
다음 단계의 근거로 사용한다. 매 24시간 Telegram에 HTML 보고서를 보내며, 이 자동 생성 보고서는
`.experiment-control/reports/`에 보관하고 커밋하지 않는다.

## 종료 후

통과한 전략도 실계좌로 바로 전환하지 않는다. 최소 1개월 paper 주문으로 신호-주문-체결-포지션
대조를 실행한다. 새틀라이트는 반기 리밸런싱 전략이므로 full lifecycle 검증에는 최소 한 번의
반기 리밸런싱이 필요하다.
