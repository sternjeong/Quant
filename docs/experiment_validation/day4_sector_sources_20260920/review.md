PIT 관련 파일명에서 새 자료는 발견하지 못했다. 검색 범위는 `local_input_delta.json`에
기록했다. 외부 데이터의 존재 여부를 단정하는 결과는 아니다.

[2022-03-31 S&P DJI/MSCI 공동 공지](https://www.msci.com/documents/1296102/29559863/GICS_Press_Release_31_March_2022.pdf/f0ac4118-d6c3-4456-3c7b-2b0174099e4e?t=1648760411652)
원문 PDF를 확보했다. 1쪽은 GICS Direct/S&P 지수의 변경 시점을 2023-03-17 업무 종료 후로
설명한다. 이는 기업별 과거 섹터 전체 목록이 아니다.

[2023-05-02 MSCI 공지](https://app2.msci.com/webapp/index_ann/DocGet?format=html&lang=en&pub_key=9piYXWAaifg%3D)
원문 HTML에는 GMT 발표시각과 기업별 변경 코드가 있다. 미국 구간 62행을 추출하고 공지의
선언 개수와 대조했다. 그중 섹터 코드가 달라지는 행은 20개(25→30: 3, 45→20: 7,
45→40: 10)다. 나머지 42개는 하위 분류 코드 변경이다. 이 수치는 **MSCI 공지의 미국
구간**에 관한 것으로, S&P500 종목 수나 S6 인증 종목 수가 아니다.

| 구분 | 원문에서 확인한 값 |
| --- | --- |
| MSCI 발표시각 | 2023-05-02 22:21 UTC |
| 해당 목록의 지수 범위 | MSCI Global Standard Indexes |
| 해당 목록의 변경 효력 | 2023-05-31 종가 후 / 2023-06-01 유효 |
| 별도로 언급된 GICS Direct/S&P 변경 | 2023-03-17 업무 종료 후 |
| 목록의 확정 여부 | 적용 전 수정될 수 있는 예정 목록 |

따라서 MSCI 목록의 `CURRENT`를 같은 날짜 S&P500 섹터로 읽거나, 5월에 발표된 기업별
자료를 3월 이전에 이미 알려진 것으로 처리하면 원문이 뒷받침하지 않는 입력이 된다.
신규 파일에는 원문의 범위/시각을 구분해 기록했으며, 체결 시각으로 임의 변환하지 않았다.
원문에는 안정적인 증권 ID가 없어 회사명을 ticker로 자동 연결하지 않았다.

S&P의 2022-06-30 공지는 웹 열람이 가능했으나 VM 원문 요청은 HTTPError로 실패했다.
처음 실패 시 HTTP 숫자 코드는 보존되지 않았으므로 이를 403 등으로 추정하지 않는다.
해당 PDF나 첨부 전체 목록을 확보했다고 주장하지 않는다. 실패 receipt도 보존했다.
