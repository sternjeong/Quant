## 분할·배당·가격 조정

provider `Stock Splits` 비영 값은 6건이다. XLB/XLE/XLK/XLU/XLY의 2025-12-05 2:1은
[발행사 공지](https://investors.statestreet.com/investor-news-events/press-releases/news-details/2025/State-Street-Investment-Management-Announces-Share-Splits-for-Five-Select-Sector-SPDR-ETFs/default.aspx)와
일치한다. 5건 모두 저장 Close/전일 Close는 약 0.991~1.007로 이미 연속적이다.
별도 2배 주식수 효과를 더하면 이중 반영된다.

나머지는 XLF의 2016-09-19 provider 값 1.231이다. [OCC 공지 39575](https://www.miaxglobal.com/sites/default/files/alert-files/XLF_Distribution_39575.pdf)는
이 날을 XLRE 현물 분배의 ex-date로 설명한다. 이를 단순 1.231:1 주식분할로 해석하지 않는다.
원 가격을 보존하며 총수익 조정 좌표에 XLRE 분배를 다시 더하지 않는다. 실제 수량 원장이 필요하면
공식 분배비율·현금·주식 원장을 별도 검증해야 한다. provider 사건분류가 경제적 사건을 완전히
설명한다고 주장하지 않는다.

`corporate_actions.csv`에 모든 배당·자본이득·분할을 기록했다. 조정계수의 하루 변화가 2%를
넘은 **27건**은 전부 해당 provider 배당행과 일치한다. 조정종가 하루 변동 절대값 25% 초과는
0건이다. 2%/25%는 오류 탐지를 위한 고정 진단 경계일 뿐 전략 파라미터·제외 기준이 아니다.
수치가 크다는 이유로 수정하거나 절삭하지 않았다. 27개 배당의 금액을 독립적으로 재구축한 감사는
아니며 단일 vendor 의존성은 남는다.

`adjusted_open = Open × Adj Close / Close`. 같은 행의 조정계수로 O/H/L/C 좌표를 일치시키며
장중 `AdjClose/AdjustedOpen = Close/Open`을 테스트했다. 저장 OHLC는 분할이 반영된 provider
좌표이며 완전한 당시 원시 호가가 아니다. 이 연구 좌표에서 배당/분할을 다시 더하지 않는다.
조정계수 자체를 신호 변수로 쓰지 않는다. 현재 조회 빈티지의 과거 가격 개정 가능성은 남으며,
이를 당시 발표된 발행주식수/구성종목의 증거로 사용하지 않는다.

## 시간대·다음 시가·데이터 누수

모든 일봉 라벨을 UTC로 읽어 America/New_York 자정으로 돌아오는지 확인했다(98,245행).
자정은 세션 라벨이며 정보가 자정에 알려졌다는 뜻이 아니다. 신호는 당일 거래소 종가 이후,
주문은 다음 세션 시가다. [NYSE 거래시간](https://www.nyse.com/trade/hours-calendars)을 근거로
정규 09:30~16:00와 조기 폐장·DST를 달력에 반영했다. 독립 달력에는 2012-10-29/30,
2018-12-05, 2025-01-09 특별 휴장이 포함되며 저장 가격도 이 날들을 포함하지 않는다.
[2025-01-09 NYSE 휴장 공지](https://ir.theice.com/press/news-details/2024/The-New-York-Stock-Exchange-Will-Close-Markets-on-January-9-to-Honor-the-Passing-of-Former-President-Jimmy-Carter-on-National-Day-of-Mourning/default.aspx)도 확인했다.

완료된 월말 **248개**에서 `signal_close < next_session_open`, `signal_date < fill_date`를
검사해 모두 통과했다(`monthly_session_edges.csv`). DST 전환, 주말, 조기 폐장, 특별 휴장,
누락 다음 시가를 별도 테스트했다. 부분 월인 2026-09를 월말 신호로 사용하지 않았다.
이 파일은 시각 경계 감사이며 실제 후보 리밸런싱 주문 로그는 Day 3/6에서 만들어야 한다.

기존 참고 코드의 shift(1) close-to-close는 next-open 체결 엔진이 아니다. 합성 가격에서
신호 종가 100, 다음 시가 109, 다음 종가 110이면 신규 매수의 비용 전 수익률은 **0.917431%**다.
기존 함수는 **10%**를 반환한다. 연구 입력 함수는 시가 109를 반환했고 이 차이를 테스트로
확인했다. 이는 입력 경계/결함 재현 검사이며 현금·드리프트·수수료까지 갖춘 완성 체결 엔진
테스트는 아니다. Day 3부터 정확한 next-open 엔진을 써야 하고 Day 6까지 오류를 미루면 안 된다.

기존 미래 주식수 fallback은 합성 자료로 재현했다. 연구 전용 `market_cap_asof`는
effective_at/available_at 모두 신호 이하이고 검증된 동일 주식수 단위여야 값을 반환한다.
미래만 있는 경우·발표시각 없음·발표 지연·미래 가격·분할 단위 불일치는 오류다. 미래 주식수의
값을 10^15로 바꿔도 과거 시가총액은 변하지 않는다. 과거가 없는 구성종목도 같은 차단 계약을
쓴다. 연구 모듈은 core/provider/broker 모듈을 import하지 않고 기존 fallback을 호출하지 않는다.

**한계**: S6 입력 패널 자체가 없으므로 이 결과는 S6 역사 전체의 누수 없음 인증이 아니다.
로컬 도입 시각과 upstream 공시시각을 구분한다. Day 1 B3의 명목상 범위가 실제 PIT 데이터
가용성을 증명하지 않는다. Day 4는 위 함수에 실제 발표시각·단위·과거 sector·상장폐지 증거를
연결한 뒤 공통 날짜 비교를 검증해야 한다. 확인 전 current sector나 최초 미래 값으로 대체 금지.
