# Day 4 재개: SEC 진단 수집기 CIK 형식 처리

변경 전 체크포인트: `20260920T012004Z_day4-sec-cik-type`.

최초 진단은 Agilent 주식수 concept를 HTTP 200으로 저장했으나 submissions 응답은
정수 CIK와 직접 비교하는 코드에서 거절됐다. SEC의 같은 식별자를 정수 또는 0으로 채운
숫자 문자열로 표현할 수 있도록 검증한다. 다른 CIK, 결측, 소수, bool은 계속 거절한다.
이를 증권 종류나 과거 ticker 동일성 인증으로 확대하지 않는다.

원 응답은 형식 검증 전에 보존하고, 최초 `sec_access.json`은 덮어쓰지 않는다.
실패했던 submissions 한 요청만 별도 receipt로 다시 조회한다. 원문 해시와 조회시각을
기록하라는 프로토콜 데이터·실행 가정 2번을 따르는 진단 코드 결함 수정이다.
기존 Day 4 입력 인증 조건과 후보·기준선·게이트는 변경하지 않는다.
새 SEC 자료는 출처 확인용이며 S6 시총·신호·성과에는 아직 사용하지 않는다.
