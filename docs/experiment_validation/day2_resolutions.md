# Day 2 감사 해석 및 데이터 계약

2026-09-19 UTC. 변경 전 체크포인트: `20260919T154701Z_day2-data-contract`.
후보 수·규칙·기준선·선택 게이트는 변경하지 않는다. 성과 비교 없이 아래 사항을 고정했다.

1. **원본과 후속 판단의 관계**: `spec.json`, `manifest.json`, `snapshot_lock.json`은
   보류 당시 증거이므로 바꾸지 않는다. `day1_resolutions.md` 및 그 뒤의 Day 1 완료 기록을
   후속 위임 판단으로 함께 읽는다. 기존 검사기의 BLOCKED는 원본 상태 검사 결과로 보존한다.
   이번 별도 manifest에는 두 계층의 해시를 기록한다. 근거: 프로토콜 Day 1 해시 보존 조건과
   사용자의 이번 "Day 2만" 지시. Day 1 완료 판정을 새로 하거나 원본을 재고정하지 않는다.
2. **결측과 상장**: 상장 전 공백과 거래소 휴일은 내부 결측과 구분한다. 필수 OHLC/Adj Close,
   신호 웜업 또는 다음 시가가 빠지면 해당 계산을 오류로 중단한다. ffill/bfill, 0 수익률,
   종목 제거, 짧은 lookback으로 대신하지 않는다. ETF 첫 관측일을 법적 상장일로 단정하지
   않는다. 종목의 상장폐지/거래정지 때도 마지막 가격 영구 유지나 데이터 없는 종목 제거를
   금지한다. 근거: 데이터 가정 1·3, 미설명 결측/미래 유니버스 탈락 게이트.
3. **프록시 범위**: XLC→VOX는 장기 표본 전체에 적용한다(원 프로토콜 데이터 가정 3).
   XLRE→VNQ와 실제 XLRE 전환은 이미 존재하는 Day 1 B2 판단을 적용하며 새 프록시는
   추가하지 않는다. VNQ만 같은 요청 기간으로 별도 조회하고 원래 19개 가격은 갱신하지 않는다.
   전환일은 저장된 실제 XLRE 첫 관측일 2015-10-08이다. 그 날 시가까지 VNQ의 overnight를
   사용하고 시가부터 XLRE의 intraday 수익률을 이어 붙이는 전향적 연결을 감사한다.
   전일 proxy close→당일 proxy open→당일 actual close/open 순서이며 미래 가격에 맞춘
   과거 수준 재조정이나 서로 다른 ETF 가격 수준의 단순 연결은 금지한다. 이후 백테스트에서
   보유분 전환은 매도·매수 양쪽 비용을 내야 한다. 이 날 신규 실제 자산의 종가를 전일
   신호에 넣을 수 없다. Day 2는 이음매 데이터만 검증하며 포트폴리오 성과는 계산하지 않는다.
4. **조정과 분할**: provider OHLC를 원시 거래가격이라고 단정하지 않는다. Yahoo의
   split-adjusted OHLC와 Adj Close를 함께 보존하고, 연구용 adjusted open은
   `Open * Adj Close / Close`로 같은 행에서만 계산한다. 조정계수는 신호 변수가 아니며,
   이 좌표에서는 배당·분할을 추가로 더하거나 주식수를 다시 늘리지 않는다. 시가 체결의
   실제 수량 원장은 별도 단위 일관성 검증이 필요하다. 근거: 데이터 가정 1·2와 원 spec의
   adjustment/dividend double-counting 금지. 사후 개정된 가격 빈티지는 PIT 공시 증거가 아니다.
5. **미래 발행주식수 차단**: 연구 전용 입력 함수는 effective_at과 available_at 모두
   신호 종가 이하이고 시가총액 계산 가격과 주식수의 날짜/분할 단위가 맞는 자료만 허용한다.
   과거 자료가 없거나 발표시각/단위를 입증할 수 없으면 명시적 오류로 중단한다. 기존 core의
   가장 이른 미래 주식수 fallback, 미래 구성종목 fallback, 현재 sector fallback은 이 실험에서
   호출하지 않는다. 근거: Day 1 B3가 Day 2에 부여한 "미래 발행주식수 fallback 미사용 확인"과
   데이터 누수 탈락 게이트. 연구 전용 함수를 합성 입력으로 검증하고 기존 결함과 대조한다.
   이는 아직 없는 S6 전체 입력 패널을 인증하는 것이 아니며, Day 4는 발표시각·과거 sector·
   상장폐지 가격을 실제로 확보하여 검증해야 한다. 로컬 도입 커밋 날짜로 이를 대신하지 않는다.
6. **시간대와 체결 경계**: America/New_York 자정은 일봉의 세션 라벨이다. 실제 신호시각은
   거래소 종가시각(조기 폐장 포함), 체결시각은 다음 거래 세션 시가다. 독립 XNYS 달력으로
   결측/휴일/DST를 검사하고 달력 및 패키지 버전을 별도 보존한다. 달력 패키지는 임시 경로에만
   설치하며 운영 환경은 바꾸지 않는다. 종가 shift(1) 참고 엔진은 승인된 체결 엔진이 아니며
   Day 3 실행 전에 실제 Open을 사용하는 엔진이 필요하다(Day 6에서 다시 로그 감사).

자동 생성 일일 HTML, 런타임 상태, 기존 미커밋 연구는 게시 대상에서 제외한다. 별도 연구
브랜치에서 이번 산출물과 필요한 기존 검증 증거만 게시하는 기존 git 관례를 따른다.
