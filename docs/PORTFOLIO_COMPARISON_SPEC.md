# 포트폴리오 비교 추적 (설계, 2026-09-28)

> 상태: 설계 확정 → 구현. 사용자가 세 가지를 직접 골랐다(아래 "결정").
> 요청 원문 요지: "여러 포트폴리오를 등록해서 지금 수익률을 보고 싶다. 내 포트폴리오 A를 고집했으면 지금 얼마인지,
> 그냥 S&P500을 샀으면, 그냥 META를 샀으면 — 이걸 저장해두고 미래에 확인해서 **전략을 따르는 게 맞았는지 판단**하고 싶다.
> 티커·평단·주수를 기록하고, 내가 얼마나 뻘짓했는지 혹은 네 말을 얼마나 믿어도 되는지 보겠다."

## 1. 이미 있는 것 / 없는 것 (2026-09-28 코드 확인)

| | 현재 |
|---|---|
| `portfolio_holdings` + `core/portfolio.py` | **실제 보유 1벌**(티커·수량·평단·매수일·논지). 이름도 그룹도 없어 여러 개를 나란히 둘 수 없다 |
| `core/champion_performance.py` | 챔피언 **전략**의 자산곡선을 SPY·60/40과 비교. 사용자가 직접 만든 임의 포트폴리오는 대상이 아니다 |
| `champion_ledger_entries` | 챔피언 전략을 따랐다면의 일별 자산곡선 |
| **없음** | **이름 붙인 포트폴리오 여러 개**를 저장하고 시간에 따라 나란히 비교하는 것 |

"SPY만 샀을 때", "META만 샀을 때"는 결국 **티커 1개짜리 포트폴리오**라 같은 구조로 담긴다 — 별도 개념을 만들지 않는다.

## 2. 결정 (사용자 선택)

1. **거래 기록**: 기본은 고정(만들 때 넣은 것 그대로), 원하면 **나중에 매수·매도를 추가**할 수 있다.
   → 입출금이 있는 구간이 생기므로 **시간가중수익률(TWR)**을 같이 보여준다(아래 3-2).
2. **통화**: **달러 기준과 원화 환산을 둘 다** 보여준다. 환율은 이미 매일 받아오는 FRED `DEXKOUS`를 쓴다(추가 비용 0).
3. **위치**: 퀀트 대시보드(app.)의 **새 페이지**. 기존 "포트폴리오 관리"(실제 보유 1벌) 옆에 둔다.

## 3. 자료 구조와 계산

### 3-1. 표

- `tracked_portfolios` — `id, name(고유), kind, started_on, note, archived_at, created_at`
  - `kind`: `actual`(내 실제 선택) / `benchmark`(그냥 ~를 샀다면) — 화면에서 묶어 보여주기 위한 표시일 뿐, 계산은 같다.
- `tracked_portfolio_trades` — `id, portfolio_id, ticker, trade_date, shares, price_usd, fee_usd, note, created_at`
  - `shares`가 **양수면 매수, 음수면 매도**. 고정 포트폴리오는 시작일 매수 행만 있는 상태다.

스냅샷 표는 **두지 않는다**: 거래와 과거 시세만 있으면 곡선 전체를 언제든 다시 계산할 수 있고, 그래야 중간에 빠진 날이
생기거나 스냅샷이 낡아 틀리는 일이 없다. 대신 계산 결과를 화면 캐시에 담는다.

### 3-2. 수익률

매일의 평가액 V(t)와 그날의 외부 유입 F(t)(매수 금액 − 매도 금액)를 만들고

```
일간수익률 r(t) = (V(t) − F(t)) / V(t−1) − 1
TWR = ∏(1 + r(t)) − 1
```

로 잇는다(일별 연결 TWR). 이러면 **언제 돈을 더 넣었는지가 성적에 섞이지 않아** 포트폴리오끼리 공정하게 비교된다.
거래를 나중에 추가하지 않은 고정 포트폴리오에서는 TWR이 단순 수익률과 같아진다.

함께 보여주는 것:
- **단순 수익률** = (현재 평가액 − 투입원금) / 투입원금 — 사람이 체감하는 값
- **원화 기준**: 같은 계산을 `평가액 × 그날 환율`로 한 번 더 한다. 달러 수익률과 원화 수익률의 차이가 곧 환율 효과다.

미국 휴장일·환율 결측일은 **직전 값으로 채운다**(둘 다 거래가 없던 날이라 평가액이 변하지 않는다).

### 3-3. 정직하게 표시할 것

- 배당은 **반영하지 않는다**(가격만). SPY처럼 배당이 있는 종목은 실제보다 낮게 보인다 — 화면에 명시한다.
- 수수료·세금은 입력한 `fee_usd`만 반영한다.
- 시작일이 서로 다른 포트폴리오를 같은 그래프에 놓을 때는 **각자의 시작일 = 0%** 로 그린다. 기간이 다르면 표에 기간을 같이 적는다.

## 4. 화면 (app/pages)

- **목록**: 포트폴리오별 현재 평가액·투입원금·수익률(달러/원화)·기간·마지막 거래일
- **비교 그래프**: 선택한 포트폴리오들의 수익률 곡선(달러/원화 전환)
- **만들기**: 이름·시작일·메모 + 거래 줄(티커·날짜·주수·단가) 여러 개
- **간편 추가**: "그냥 SPY를 샀다면" — 티커와 금액·날짜만 주면 그 날 종가로 주수를 계산해 넣는다
- **거래 추가**: 기존 포트폴리오에 나중 매수·매도를 덧붙인다

## 5. 만들지 않는 것

- 실제 증권사 계좌 연동(이미 Alpaca paper 경로가 따로 있다)
- 자동 매매·주문(이 페이지는 **기록과 비교만** 한다)
- 일별 스냅샷 잡(3-1 참고 — 다시 계산하는 편이 안전하다)
