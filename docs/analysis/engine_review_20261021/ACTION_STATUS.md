## 반복을 중단할 작업

- 독립 입력 자료 없이 동일한 ETF 가격의 top N·모멘텀 길이·손절률 격자를 확장하지 않는다.
- PIT 구성과 상장폐지 가격이 없는데 개별주 알파 본 실험을 다시 돌리지 않는다. 선행 입력 감사의 `NOT_EVALUABLE_DATA`는 전략 실패가 아니다.
- 5년 중첩 창 117개의 승리 비율을 독립 117회 검증 또는 미래 승리 확률로 바꾸지 않는다.
- `PASS_FORWARD_CANDIDATE`를 SPY 초과수익·통계적 통과·챔피언 채택과 동일하게 집계하지 않는다.
- `core-universe-expansion-v1`의 FAIL을 추가 자산 가설의 반증으로 세지 않는다.

## 아직 검증이 필요한 결정

1. 새 청산 회계 영향 작업의 VM 결과를 받고, 차이 부호가 바뀐 창과 미납세금 집중 월을 확인한다. 현 챔피언·SPY 외 P1ST·SSO 결합까지 확장할지 이 결과를 보고 새 ID로 정한다.
2. 전진 원장은 수정 배포 후 새 상태 파일의 `days`, `data_error`, v1 `excluded_incomplete_signal_records`를 실제 운영 가격으로 확인한다. 이전 일간 수익을 소급해 채우지 않는다.
3. 가설 계보에는 부모 연구, 처음 본 구간, 사용한 자료 버전, 후보 수, 판정 지표, 최종 운용 반영 여부를 기록한다. 과거 결과를 독립 표본외 검증으로 다시 이름 붙이지 않는다.
