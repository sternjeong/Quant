# 티커 뉴스 리서치: V1과 V2

## V1 — 지금 운영

- 대상은 처음 실행 시 챔피언 전략의 17개 코어 ETF이며, 뉴스 리서치 화면에서 자유롭게 바꿀 수 있다.
- 매일 한국시간 07:30에 사용 가능한 `FINNHUB_API_KEY`와 `FMP_API_KEY`로 최근 24시간 안팎의 뉴스 **메타데이터**를 수집한다. 한 공급자가 인증·요금제·네트워크 오류를 내면 그 회차에서는 한 번만 기록하고 나머지 공급자로 계속 진행한다.
- 저장하는 항목은 공급자, 제목, API가 제공한 짧은 설명, 발행 시각, 이벤트 분류, 원문 URL이다. 기사 본문은 요청·스크래핑·저장하지 않는다.
- Gemini 키가 있으면 티커별로 제목과 설명을 종합해 한국어 불릿 요약을 만든다. 각 사실에는 내부 기사 ID를 붙이며, 장애 또는 무료 한도에서는 제목 기반 대체 요약을 남긴다.
- 텔레그램에는 짧은 요약과 HTML 첨부 보고서를 보내고, Streamlit의 **뉴스 리서치** 페이지에서는 원문 링크와 이력을 확인한다. `/news`, `/news XLK`는 최신 저장 요약을 읽는다.
- 이 정보는 매매 신호나 추천이 아니다. 제목이 상충하거나 빠진 경우 원문과 원 발표를 확인해야 한다.

## 왜 이 범위인가

구독 매체가 없는 현재 단계에서는 유료 기사 전문을 수집하는 것보다, 이미 보유한 무료 API의 출처·시각·링크를 정확히 남기는 편이 비용과 재현성 면에서 낫다. API 제공 범위는 공급자별로 달라질 수 있으므로, 화면의 기사 수가 곧 시장 전체 기사 수를 뜻하지는 않는다.

## V2 — 14일 운영 후 필요한 경우만

다음 조건이 충족될 때만 추가한다.

1. V1 일일 보고가 14회 이상 누적되고, 필요한 티커에서 출처 부족·중복·지연 문제가 실제로 기록된다.
2. 사용자가 보고 싶은 공개 채널 또는 공식 기관을 목록으로 확정한다.
3. 추가 데이터가 기존 가격·펀더멘털·매크로 정보와 분리된 설명력이나 의사결정 가치를 보이는지 검토한다.

후보 순서는 다음과 같다.

- **공식 1차 자료:** 기업 IR RSS/보도자료, SEC 공시, Fed·BLS·BEA·CFTC 같은 공개 기관 발표. 티커나 이벤트에 직접 연결하고 발표 시각을 보존한다.
- **YouTube:** Google Cloud 프로젝트의 YouTube Data API로 사용자가 지정한 공개 채널의 새 영상 메타데이터(제목·설명·발행 시각)만 수집한다. 공개 자막을 대량으로 우회 수집하지 않는다. 공식 자막 다운로드는 OAuth 권한이 필요한 기능이므로, 채널 운영자 권한이 없는 영상은 사용자가 허용하는 방식으로 별도 검토한다. [YouTube Data API 시작 안내](https://developers.google.com/youtube/v3/getting-started), [자막 API 권한 안내](https://developers.google.com/youtube/v3/guides/implementation/captions)
- **개인 뉴스레터·유료 매체:** 사용자가 합법적으로 접근할 수 있고 API/RSS 또는 전달 허가가 있는 출처만 추가한다. 로그인 세션 자동화, 화면 캡처 기반 대량 추출, 유료벽 우회는 V2 범위에 넣지 않는다.

V2를 시작할 때는 각 출처별로 수집 목적, 허용 방식, 갱신 주기, 보존 기간, 실패 시 동작을 문서화하고 V1 기사와 같은 출처 링크·시간 기준으로 분리 저장한다.
